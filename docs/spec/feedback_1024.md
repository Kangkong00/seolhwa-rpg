# 2026-10-24 강콩 피드백 + 무예 숙련

## 1. 지축 가르기가 칼처럼 위에서 아래로 떨어짐

- 강콩: 땅이 갈라지는 무예인데 위에서 아래로 떨어지는 것처럼 보임.
- 지금 코드(`src/scenes/skillArt.js` `artEarthCrack`)는 땅 갈라짐 그림을 돌리고 세로(`sy`)를 0→1로 늘림. 방향에 따라 늘어나는 축이 화면 세로가 되거나, 공통 연출 층·`line` 도형 연출 중 위에서 내려오는 것이 섞여 있을 수 있음 → **어느 조각이 떨어지는지 먼저 확인**(네 방향 각각 0.05초 간격 화면 찍기).
- 바라는 모습:
  1. **위에서 내려오는 것 없음.** 시작은 주인공 발 앞 바닥.
  2. 금이 **바닥에 누운 채 바라보는 쪽으로 쭉 뻗어 나감**(0.3초, 굵기는 그대로 길이만 0→1). 옆(좌·우)은 화면 가로로, 위·아래는 화면 세로로 뻗되 그림을 세로 0.6배로 눌러 땅에 누운 느낌.
  3. 금이 지나간 자리에서 **주황빛이 솟고 돌 조각이 위로 튐**(아래에서 위로) → 맞힘 판정은 금 끝이 지나가는 순간 그 자리 몬스터.
  4. 0.5초 남았다가 흐려짐.
- 시험: 네 방향 화면 찍기를 `docs/`에 남기고, 금 그림의 시작점이 늘 발 앞인지(위쪽 바깥에서 들어오지 않는지) 값으로도 검사.

## 2. 화면 위아래가 조금 잘리고 검은 공간이 많음 (원인 확인 필요)

- 강콩 아이폰. 지금 캔버스는 `visualViewport` 크기로 만들고(`src/main.js`), `#game`은 화면 전체(`inset: 0`). 아이폰 가로에서는 노치·홈 막대 쪽 안전 영역과 사파리 주소창 때문에 **캔버스 크기와 실제 화면 크기가 어긋나** 검은 띠가 생기거나 위아래가 잘릴 수 있음.
- 바라는 것:
  - **게임 그림(맵)은 화면 끝까지 꽉**(노치 옆·홈 막대 아래까지). 검은 띠 없음.
  - **단추·체력바 같은 화면 글자는 안전 영역 안**(지금처럼 `env(safe-area-inset-*)`).
  - 사파리 주소창이 나왔다 들어가도, 홈 화면 앱으로 열어도 같게.
- 확인 방법: Playwright로 아이폰 가로(844×390, 안전 영역 좌우 47·아래 21 흉내)와 홈 화면 앱(standalone) 두 경우 화면 찍기 → 검은 띠·잘림이 없는지. 맵이 화면보다 작은 경우(맵 높이 768은 화면보다 큼)는 해당 없음.
- 강콩이 화면 찍기를 보내 주면 기획 쪽이 함께 봄.

## 3. 숫자패드 단추가 너무 큼 → 줄이고 오른쪽 끝으로

- 시안 `docs/numpad_small_mock.png`(아이폰 가로 844×390): 지금 244×174px → **175×126px**(가로 28%·세로 28% 줄어듦).
- `data/game.json` `actionPad`: `slot` 54 → **40**, `gap` 6 → **3**, `margin` 16 → **6**(오른쪽·아래, 안전 영역 더함), `attackW` 64 → **46**(공격 높이 = 2칸 + 사이 = 83).
- 칸 안 아이콘·번호 글자·기다리는 초 글자도 같은 비율로 줄임(번호 9 → 8px, 초 15 → 12px).
- 손가락 닿는 영역은 그림보다 조금 넓게(칸 사이 3px까지 다 누름 영역) — 작아져도 잘 눌리게. 겹치지 않는지 시험.

## 4. 무예 숙련 (2026-10-24 강콩: "지난 표대로 진행")

`mastery_fusion.md` 숙련 제안 v1의 **무예 줄**만 지금 만듦. 능력치 숙련·손때(보류)는 나중.

| 항목 | 값(임시, `data/skills.json` `mastery`에 둠) |
|---|---|
| 등급 | 1 ~ 10 (배우면 1등급, 횟수 0) |
| 무엇을 세나 | 그 무예를 써서 **몬스터를 1마리 이상 맞힌 번 수**(한 번 쓸 때 여러 마리·여러 번 맞혀도 1) |
| 세는 몬스터 | 내 구간보다 **한 구간 아래까지**의 몬스터(구간은 `tiers.md` 레벨 구간), 우두머리는 늘 셈, 분신(보상 없는 것)은 안 셈 → 들쥐로 꼼수 막기 |
| 다음 등급까지 | 20 × 지금 등급 (2등급 20, 3등급 +40 … 10등급까지 모두 900번) |
| 등급마다 | 데미지 +5%, 기다림 −2% → 10등급 = 데미지 +45%, 기다림 −18% |
| 5·10등급 | 범위 +10%씩(10등급 = +20%) |
| 숨 고르기(회복) | 데미지 대신 회복량 +5%/등급 |
| 받아치기(자세) | 반격 배율 +5%/등급 |
| 패시브 9개 | 숙련 없음(쓰는 동작이 없음) |

- 기다림 줄이기는 팔찌·패시브 `cooldownCut`과 더해 최대 0.5(지금 규칙 그대로).
- **등급이 오르면**: 머리 위에 짧은 붓글씨 "검풍 숙련 3" + 작은 소리, 10등급은 금빛.
- **무예창**: 무예마다 등급 숫자와 다음 등급까지 막대. 무예 칸(숫자패드) 아이콘에는 표시 안 함(작아서).
- **저장**: `skillMastery: { 무예id: 횟수 }`. 함께 `skillsEverLearned`(한 번이라도 배운 무예 목록, 지금 배운 무예로 채워 시작) — 다음 단계 무예 합성에서 트리 검사·"다시 배울 수 없음"에 씀(`fusion_design.md` 1-3). 이번에는 저장만 하고 트리 검사는 아직 바꾸지 않음.
- 계산은 `src/core/`(예: `mastery.js`)에, 화면은 읽기만(서버 대비).
- **관리자 창**: 무예 하나·전부의 숙련 등급 바로 정하기(1~10).
- 시험: 세는 조건(낮은 구간 몬스터 안 셈·한 번에 1), 등급 계산(19번 = 1등급, 20번 = 2등급, 900번 = 10등급), 데미지·기다림 배율, 저장 → 불러오기, 2분 무작위 시험 오류 0.
