## 2. 몬스터 걷기

- **뒤로 걷던 것 = 그림 문제(고쳐 둠)**: 구미호의 그림자·멧돼지·쇠엄니 산저·반달곰·흑웅의 옆모습, 물뱀·구렁이의 옆 걷기가 오른쪽을 보고 있었음(가공 때 자동 판정이 반대로 걸림) → 모두 **왼쪽을 보게** 다시 만듦(`assets/monsters/<id>/side*.png`). 코드 규칙(옆모습 = 왼쪽, 오른쪽으로 갈 때 뒤집기)은 그대로. 혹시 코드가 몬스터마다 뒤집기 값을 따로 두었다면 지움.
- **벽·바위 위를 걷던 것**: 1의 새 격자로 대부분 풀림. 코드 쪽 확인:
  - 몬스터가 생길 자리는 **갈 수 있는 칸에서만**(구역 사각형 안에서 고르되 막힌 칸이면 다시 고름, 10번 실패하면 그 구역 안 가장 가까운 갈 수 있는 칸).
  - 돌아다닐 목표점도 갈 수 있는 칸, 그리고 **지금 서 있는 곳과 이어진 칸**(섬처럼 떨어진 곳은 안 감).
  - 움직일 때 발 한 점이 아니라 **몸 반경**(몬스터 표시 키의 약 20%, 최소 4px)으로 막힘 검사 — 가로·세로 따로 미끄러지게(주인공과 같은 방식).
  - 돌진·밀려남·순간이동·분신·우두머리 덮치기도 같은 검사(벽에서 멈춤, 순간이동 자리는 갈 수 있는 칸만).

## 3·4. 관리자 창

- **스크롤**: 목록(물건·맵·우두머리 등)이 손가락으로 위아래로 넘어가게. 창 안에서는 게임 화면이 터치를 가져가지 않게(창이 열리면 Phaser 입력 끄기 또는 이벤트 전파 막기), `overflow-y: auto` + `touch-action: pan-y` + iOS 관성 스크롤. PC는 마우스 휠.
- **글자 잘림**: 아이폰 가로 화면(약 844×390, 노치 safe-area 포함)에서 창이 화면 안에 다 들어오게(최대 높이 = 화면 높이 − 위아래 여백). 줄이 길면 줄바꿈, 단추 글자는 줄임표(…) 대신 글자 크기를 조금 줄임. 탭 이름 4개가 한 줄에 다 보이게.
- **물건 주기**: 한 번 누르면 **1개**. 창 위에 수량 단추 `1 · 10 · 100` (고른 것이 강조, 기본 1). 장비는 수량과 상관없이 1개.
- 관리자 창에도 **"가방 비우기"**(장착한 것 빼고 전부, 확인 창) — 시험할 때 가방이 차서.

## 5. 무예 연출 — "엄청나게" 화려하게

모든 액티브 무예에 아래 **공통 층**을 얹음(무예마다 색은 그 무예 `color`·`trailColor`, `colorFromWeapon`이면 칼 색). 값은 `data/skills.json` 맨 위 `fxCommon`에 두어 조정.

1. **시전 순간(0~0.25초)**: 화면이 살짝 어두워짐(검정 25%, 무예가 끝나면 0.2초에 걸쳐 밝아짐) · 주인공 둘레로 빛 알갱이 16개가 빨려 들어옴(기 모으기) · 발밑에 무예 색 원 문양(빙글 돎) · 무예 이름을 붓글씨 느낌 큰 글씨로 화면 위 가운데 0.8초(테두리 + 그림자, 빠르게 커졌다 자리 잡음).
2. **실행**: 지금 연출 크기 **1.6배**, 겹을 3겹으로 — 흰 중심 빛 + 무예 색 몸통 + 바깥 잔광(흐려지며 0.4초 남음). Phaser 4 빛 번짐(glow/bloom 후처리)을 무예 연출 층에만. 알갱이 3배(구름·불꽃·별·꽃잎 등 무예에 맞게), 땅 충격파 고리 2~3겹, 잔상(주인공 그림 3장이 흐려지며 따라옴 — 돌진·연속 베기), 시작·끝에 화면 전체 무예 색 섬광(25%, 0.1초).
3. **맞힐 때**: 몬스터마다 큰 섬광 + X자 베인 자국 + 파편 8개 + 데미지 숫자 1.3배(무예로 맞힌 숫자는 무예 색 테두리). 여러 마리를 맞히면 맞힌 수만큼 짧은 "타다닥" 연속음.
4. **흔들림·멈춤**: 화면 흔들림 1.5배, 히트스톱 1.5배(지금 값에 곱함).
5. **궁극기(칠성검무)**: 화면을 더 어둡게(45%) + 하늘에 북두칠성 7점이 차례로 켜지고 선으로 이어짐 → 7곳을 벨 때마다 그 별이 터짐 → 마지막 큰 폭발에서 화면 흰 섬광 + 느린 화면 0.3초(시간 0.3배).
6. **성능**: 아이폰에서 60프레임 유지가 우선. 알갱이 상한(화면에 동시 300개), 빛 번짐은 아이폰에서 느리면 끄는 스위치(`fxCommon.bloom`).

## 9. 타격 효과 더 (평타)

## 10. 가방에서 버리기

- 가방에서 물건을 누르면 나오는 정보창에 **버리기** 단추. 여러 개 있는 물건은 수량 고르기(1 · 10 · 전부 · −/+), 확인 창("○○ N개를 버릴까요?").
- 버린 물건은 **주인공 발 앞 바닥에 떨어짐**(전리품처럼 보이고 다시 주울 수 있음), 60초 뒤 사라짐. 장착한 물건은 버리기 흐리게("벗고 버리기"), 엽전은 버리기 없음.

## 11. 몬스터 수 조금 더
