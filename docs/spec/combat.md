# 때리기·싸움 규칙

> 맞히기, 히트, 몬스터 반격, 주인공 체력. CLAUDE.md의 목차에서 연결됨. 내용을 고칠 때는 이 파일에서 해당 부분만 고치고, 파일 전체를 다시 쓰지 않음.

## 때리기 (첫 단계, 몬스터 반격 없음)

- 바라보는 방향 바로 앞(`attack.reach` 30px, 폭 `attack.width` 28px) 안의 가장 가까운 몬스터 1마리를 맞힘. 맞으면 하얗게 번쩍 + 맞은 방향으로 밀려남(벽은 통과 안 함) + 잠깐 멈칫 + 데미지 숫자가 떠오름.
- 체력 0이면 납작해지며 흐려져 사라지고, 그 구역의 `respawnMs` 뒤에 다시 생김.
- 수치(모두 임시값): `data/game.json`의 `attack`(데미지 1, 간격 400ms, 내딛기·닿는 거리·밀림·멈칫), `hitFx`(번쩍 시간, 숫자 모양, 쓰러지는 시간), `data/monsters.json`의 `hp`(들쥐 3 → 3대에 쓰러짐, 큰 들쥐도 같은 조건 원칙으로 3, 확인 필요). 레벨·경험치는 아직 없음.
- 규칙 코드는 `src/core/combat.js`(대상 찾기·맞히기)와 `src/core/monsters.js`(밀려나기·멈칫), 연출은 `src/scenes/MonsterView.js`·`damageText.js`, 버튼은 `src/ui/attackButton.js`.

## 싸움 규칙 (2026-10-10 강콩 확정, 수치는 모두 임시값)

- **들쥐·큰 들쥐는 먼저 덤비지 않고, 맞으면 반격**(쫓아와서 문다). 큰 들쥐도 같은 조건.
- 반격 중인 몬스터는 자기 구역을 벗어나 쫓아올 수 있음. 주인공이 멀어지거나(예: 200px) 한동안(예: 8초) 서로 안 때리면 포기하고 자기 구역으로 돌아감. 거리·시간은 `data/`.
- **맞는 모션은 그림 없이 코드로**(기획 판단, 2026-10-10): 하얗게 번쩍, 맞은 반대쪽으로 살짝 밀려남, 짧게 멈칫. 쓰러질 때는 뒤집히며 흐려져 사라짐. 주인공이 맞을 때는 붉게 번쩍 + 살짝 밀려남. 몬스터 무는 동작도 일단 코드로(바라보는 쪽으로 빠르게 튀어나갔다 돌아옴 + `step` 그림). 실제로 해 보고 밋밋하면 그때 몬스터 공격·맞기 그림을 그림.
- 주인공 체력이 0이 되면 마을(시작 위치)에서 다시 시작(임시). 체력·데미지·공격 간격·쫓는 속도는 `data/`에 임시값.
- **반영됨(2026-10-10)**: 맞은 몬스터만 반격(`aggro`). 4방향으로 쫓아와(막히면 다른 축으로 비켜 감) `biteRange` 안이면 `biteCooldownMs`마다 묾. 무는 동작은 `biteMs` 동안 바라보는 쪽으로 `lungePx`만큼 튀어나갔다 돌아오며 `step` 그림, 동작 절반에서 아직 가까우면 데미지. 주인공이 `giveUpDistance`(200) 넘게 멀어지거나 `giveUpMs`(8초) 동안 서로 안 때리면(물거나 맞으면 시간이 처음부터) 포기하고 구역으로 돌아감. 수치는 `data/monsters.json`(들쥐·큰 들쥐 같은 값).
- 주인공: 체력 `data/game.json` `player.maxHp`(10), 물리면 `playerHit`(붉게 번쩍·밀림), 0이면 화면이 어두워진 뒤 마을 시작 위치에서 체력 가득 차서 다시 시작. 체력은 맵을 옮겨도 이어짐(저장은 아직 안 함).
- 머리 위 체력바: 주인공은 늘 보임(초록), 몬스터는 다쳤거나 반격 중일 때만(빨강, `hpBar.monsterShowAlways`로 늘 보이게 바꿀 수 있음). 모양은 `data/game.json` `hpBar`.
- 쓰러짐: 하얗게 번쩍 → 몸 가운데를 축으로 뒤집히며 흐려져 사라짐. 몬스터끼리·주인공과 몬스터는 아직 서로 부딪히지 않음(겹쳐 지나감).

## 맞히기 도움 (2026-10-12 강콩: "몬스터 잡을 때 위치 맞추기가 어렵다")

- 원인(기획 진단): 4방향으로만 치는데, 맞는 상자가 앞으로 30px·폭 28px로 좁고 들쥐가 작음(28px). 아이폰 조이스틱으로 한 줄을 정확히 맞추기 어려움.
- **자동 방향 맞춤**: 공격(무예 포함)을 누를 때 둘레 `attack.assistRadius`(임시 56px) 안에 몬스터가 있으면, 가장 가까운 몬스터 쪽(4방향 중 가까운 축)으로 몸을 돌린 뒤 침. 반격 중인 몬스터를 먼저 고름. 없으면 지금 방향 그대로.
- **조금 다가가기**: 몸을 돌렸는데 그래도 닿지 않으면(안쪽 거리 > 닿는 거리) 그쪽으로 최대 `attack.assistStepPx`(임시 12px) 미끄러지듯 다가가 침. 벽은 통과 안 함.
- **맞는 상자 넓히기**: 맨손 닿는 거리 30 → 38, 폭 28 → 40. 무기는 무기별로 `data/weapons.json`에 닿는 거리·폭(목검 임시 48·44). 모두 임시값.
- 기각: 몬스터를 손으로 눌러 자동으로 쫓아가 치는 방식 — 조작 방식 자체가 바뀌어 지금은 보류(위 방식으로도 어려우면 다시 검토).
