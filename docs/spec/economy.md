# 초보 구간: 경험치·전리품·엽전·무예 (1차 시험안)

> 2026-10-12 강콩 방향, 이름과 숫자는 기획 대화 초안. **모두 임시값 — 해 보고 고침.** 숫자는 `data/`에 두어 코드 수정 없이 바꿀 수 있게.

## 방향 (강콩 확정)

- 첫 레벨업의 목적은 **무예(스킬)를 배우는 것**(바람의나라식). 의뢰는 길잡이 정도로만.
- 무예는 **엽전 + 전리품(재료)** 을 내고 배움.
- 몬스터는 그 동물다운 전리품을 떨어뜨림(들쥐 → 쥐고기 등). 필요 없는 전리품은 가게에 팜.
- 의뢰에 **시간 제한 없음**.

## 레벨 (임시, 들쥐굴 1층 기준)

- 경험치: 들쥐 4, 큰 들쥐 15.
- 다음 레벨까지 필요: 1→2 **50**, 2→3 **110**, 3→4 **240**, 4→5 **320**. 5 이후는 들쥐굴 2~3층이 생기면 정함.
- 목표 시간(누적): 레벨 2 약 3분, 3 약 10분, 4 약 25분, 5 약 45분. 해 보고 맞춤.
- 레벨이 오르면: 최대 체력 +3, 체력 가득 회복, 레벨업 연출(글자 + 소리).
- 화면: 왼쪽 위에 레벨, 체력 막대 아래 가는 경험치 막대, 엽전.

## 레벨업 연출 (2026-10-12 강콩: 효과 필요)

- 그림 없이 코드로: ① 발밑에서 금빛 둥근 고리가 퍼짐 ② 몸을 감싸는 금빛 빛기둥이 아래에서 위로 솟았다 사라짐(약 0.8초) ③ 반짝이 몇 개가 떠오름 ④ 머리 위에 붓글씨 느낌 큰 글자 `레벨 업!`과 그 아래 `레벨 3` 이 떠올랐다 흐려짐 ⑤ 체력 가득 차는 모습(체력바가 차오름) ⑥ 맑은 종소리 같은 효과음(코드 소리).
- 레벨업 순간 아주 짧은 멈춤(0.1초)과 화면 가장자리 은은한 금빛.
- 새로 배울 수 있는 무예가 생기면 화면 위에 한 줄: "늙은 군관에게 새 무예를 배울 수 있습니다".
- 색·시간은 `data/`에.
- **반영됨(2026-10-12)**: 값은 `data/economy.json` `levelUpFx`, 코드는 `src/scenes/progressFx.js` `levelUpFx`·`edgeGlow`와 `MapScene.gainExp`.
  - ① 발밑 금빛 고리 두 번(0.2초 차) ② 빛기둥: 아래가 밝은 세로 띠가 0.32초에 키의 1.7배로 솟았다가 0.48초에 가늘어지며 사라짐(몸 뒤에 진하게, 몸 앞에 옅게 — 앞에 진하면 캐릭터가 하얗게 바램) ③ 네 갈래 반짝이 9개가 몸 둘레에서 떠오르며 돌고 흐려짐 ④ 붓글씨 `레벨 업!`(30px)과 `레벨 N`(17px)이 톡 커지며 나타나 잠시 머문 뒤 떠오르며 흐려짐(1.8초) ⑤ 머리 위·왼쪽 위 체력바가 0.7초 동안 예전 체력에서 가득으로 차오름 ⑥ 맑은 종소리 두 번(코드 소리, 배음 1 : 2.76 : 5.4 : 8.93).
  - 레벨업 순간 0.1초 멈춤(히트스톱과 같은 방식) + 화면 가장자리 금빛이 0.9초 동안 은은하게 비쳤다 사라짐.
  - 새로 열린 무예(이번에 오른 레벨이 그 무예의 조건 레벨이고 아직 안 배움)가 있으면 화면 위 알림 "늙은 군관에게 새 무예를 배울 수 있습니다"(3.5초). 예전의 "레벨 N! 최대 체력" 알림은 큰 글자와 겹쳐서 뺌.
  - 붓글씨 글꼴: 나눔손글씨 붓에서 `레벨 업!`·`레벨 0~9` 글자만 뽑은 7.5KB 파일(`assets/fonts/levelup_brush.woff2`, SIL OFL, `assets/fonts/README.md`). 못 받으면 기본 글꼴로 보임.

## 가게와 회복

| 가게(사람) | 사는 것(파는 값으로) | 파는 것 |
|---|---|---|
| 주막(주모) | 쥐고기, 쌀 한 줌 | 주먹밥 5푼 — 체력 3 회복 |
| 약방(약방 영감) | 쥐수염, 쥐 앞니 | 탕약 20푼 — 체력 전부 회복 |

- 주먹밥·탕약은 가방에서 누르면 먹음. 나중에 빠른 사용 칸.
- 사람(NPC)을 누르면 창: `사기` · `팔기` · (늙은 군관은) `무예 배우기`. 팔 때는 개수 고르기.

## 길잡이 의뢰 (시간 제한 없음)

- 촌장: "곳간 뒤 쥐구멍으로 들쥐가 들끓네. 쥐고기 10개만 가져다주게." → 보상 20푼 + 주먹밥 3개, 그리고 "몸이 좀 붙으면 우물가의 늙은 군관을 찾아가 보게"(무예로 안내).
- 의뢰는 이것 하나만. 목록·지도 표시 없이 대화로만.

## 사람(NPC) 그림

- 그림이 나오기 전까지 **도포 옷 서 있기 그림을 임시로** 쓰고, 머리 위에 이름표 + 발밑 그림자. 그림은 1차 시험 뒤 Flow로 만듦.
- 아이콘: 전리품 5종 + 주먹밥 + 탕약은 `assets/items/icons/<id>.png`(2026-10-12 추가, `data/items.json` 경로와 같은 이름). 엽전은 `assets/items/icons/coins.png` — 바닥에 떨어진 엽전·화면 왼쪽 위 엽전 표시에 씀. 바닥에 떨어진 전리품도 글자 대신 이 아이콘(작게, 발밑 그림자).

## 반영됨 (2026-10-12, 1차 시험안)

숫자는 모두 `data/`에 있어 코드 수정 없이 바꿀 수 있음.

| 무엇 | 파일 |
|---|---|
| 레벨별 필요 경험치(`expToNext` 50/110/240/320), 레벨당 최대 체력 +3, 엽전 단위, 바닥 물건(주울 거리·사라지는 시간), 레벨업 연출 | `data/economy.json` |
| 몬스터 경험치(`exp`)·전리품 확률표(`drops`)·엽전(`coins`) | `data/monsters.json` |
| 전리품 5종·주먹밥·탕약 정의(겹침 `stack`, 파는 값 `sellPrice`, 먹으면 `use`, 아이콘 대신 글자 `iconText`) | `data/items.json` |
| 무예 3종(조건·내는 것·재사용 시간·효과 배율, 한자 아이콘, PC 단축키 1·2·3) | `data/skills.json` |
| 사람 5명(자리·창 단추·가게가 사고파는 것·대화) | `data/npcs.json` |
| 촌장 길잡이 의뢰 | `data/quests.json` |
| 레벨업·주움·엽전·회복·배움 소리 | `data/sounds.json` (`levelUp`·`pickup`·`coin`·`heal`·`learn`, 코드로 만든 소리) |

- **규칙 코드(화면 무관)**: `src/core/progress.js`(경험치·레벨·최대 체력), `loot.js`(드랍 굴리기·바닥 물건 줍기·사라지기), `money.js`(엽전 표시), `shop.js`(사고팔기), `skills.js`(배우기·재사용 시간), `quests.js`(의뢰), `equipment.js`(가방 겹치기·먹기·엽전).
- **경험치·레벨**: 쓰러뜨리면 바로 경험치. 레벨이 오르면 최대 체력 +3, 체력 가득, 레벨업 연출(위 "레벨업 연출", 2026-10-12에 바꿈). 레벨 5에서 멈춤(경험치 막대 가득). 쓰러졌다 다시 시작할 때도 레벨에 맞는 최대 체력.
- **화면 왼쪽 위**: `Lv N` · 엽전 / 체력 막대(숫자) / 가는 금색 경험치 막대(`src/ui/statusPanel.js`). 머리 위 체력바는 그대로.
- **드랍·줍기**: 쓰러진 자리 둘레로 튀어나와 떨어짐. 아이콘 그림이 아직 없어서 바닥에는 글자 칸(고기·쌀·가죽·수염·앞니), 엽전은 구멍 뚫린 금색 동전. 주인공이 `pickupRadius` 16 안에 오면 저절로 주움(떨어진 뒤 0.35초부터) → 머리 위에 "+쥐고기" "+3푼". 30초 뒤 사라짐(마지막 4초는 깜빡임). 맵을 옮기면 바닥 물건은 사라짐.
- **가방**: 겹치는 물건은 한 칸에 ×개수. 주먹밥·탕약을 누르면 먹음(체력이 가득하면 안 먹음). 전리품을 누르면 쓰임 안내. 가방 제목 옆에 엽전.
- **엽전 표시**: 100푼 미만 `35푼`, 이상 `1냥 2전 5푼`(0인 단위는 뺌, 예: `1냥 5전`, `10냥 7푼`).
- **사람(NPC)**: 늙은 군관(우물 왼쪽), 주모(주막 앞 길), 약방 영감(약방 앞), 갖바치(갖바치 집 앞), 촌장(촌장 집 마당). 도포 서 있기 그림 + 외곽선 + 이름표 + 그림자. 누르면 창(조이스틱 자리에 서 있어도 누를 수 있음). 창이 열려 있는 동안은 조이스틱·공격·무예 버튼을 숨김.
  - 창 단추: 주모·약방 영감 `사기`·`팔기`·`대화`, 갖바치 `팔기`·`대화`(짚신은 나중), 늙은 군관 `무예 배우기`·`대화`, 촌장 `대화`(의뢰).
  - 사기·팔기 모두 개수 고르기(−10·−·+·+10·모두). 가게는 자기가 사는 물건만 목록에 보임.
- **무예**: 공격 버튼 둘레 작은 버튼 3개(斬·息·旋, PC는 1·2·3). 안 배운 것은 흐리게(누르면 "늙은 군관에게 배웁니다" 알림), 기다리는 동안 아래부터 어둡게 덮고 남은 초.
  - 힘껏 베기: 목검이면 휘두르기, 맨손이면 주먹. 데미지·밀어내기 2배, 히트스톱 2.5배, 화면 흔들림 2배, 궤적 굵기 1.7배. 6초.
  - 숨 고르기: 최대 체력의 30%(올림) 회복 + 몸 뒤 푸른 빛 + 발밑 고리. 체력이 가득하면 쓰지 않음(기다리는 시간도 안 흐름). 30초.
  - 휘돌려 베기: 0.48초 동안 아래 → 왼쪽 → 위 → 오른쪽으로 몸을 돌리며(목검이면 내려치기 자세, 맨손이면 주먹 그림) 원형 궤적, 절반 지점에서 반지름 42 안의 몬스터를 모두 때리고 바깥쪽으로 밀어냄. 10초.
- **의뢰**: 촌장 `대화` → 맡기 → 쥐고기 10개가 모이면 `쥐고기 10개 드리기` → 20푼 + 주먹밥 3개, 늙은 군관 안내. 끝난 뒤에는 안내 말만.
- **자동 저장**: 레벨·경험치(`progress`), 엽전(`equipment.coins`), 가방 겹침(`equipment.bag: [{ id, n }]`), 배운 무예(`skills`), 의뢰 상태(`quests`). 체력과 무예 기다리는 시간은 저장하지 않음(다시 열면 가득).
- 아이콘 그림(전리품 5종·주먹밥·탕약)이 `assets/items/icons/<id>.png`로 들어오면 코드 수정 없이 그 그림으로 바뀜(엽전은 코드 그림).
