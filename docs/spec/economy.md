# 초보 구간: 경험치·전리품·엽전·무예 (1차 시험안)

> 2026-10-12 강콩 방향, 이름과 숫자는 기획 대화 초안. **모두 임시값 — 해 보고 고침.** 숫자는 `data/`에 두어 코드 수정 없이 바꿀 수 있게.

## 방향 (강콩 확정)

- 첫 레벨업의 목적은 **무예(스킬)를 배우는 것**(바람의나라식). 의뢰는 길잡이 정도로만.
- 무예는 **엽전 + 전리품(재료)** 을 내고 배움.
- 몬스터는 그 동물다운 전리품을 떨어뜨림(들쥐 → 쥐고기 등). 필요 없는 전리품은 가게에 팜.
- 의뢰에 **시간 제한 없음**.

## 이름 정하기

| 쓰임 | 이름 | 이유 |
|---|---|---|
| 돈 | **엽전**, 단위 **푼·전·냥** (1냥 = 10전 = 100푼) | 조선 후기 상평통보(엽전)의 실제 단위 관계. 게임에서는 엽전 한 닢 = 1푼으로 셈(게임 규칙) |
| 돈 표시 | 100푼 미만은 `35푼`, 그 이상은 `1냥 2전 5푼` | 처음엔 쉽게, 모이면 옛날 느낌 |

| 스킬 | **무예**, 하나하나는 그 이름(예: 힘껏 베기) | 조선 무예서 『무예도보통지』에서 따온 말 |
| 스킬 가르치는 사람 | **늙은 군관**(군대에서 물러난 무관) — 우물 광장 | 마을에 무예를 가르칠 만한 사람 |
| 경험치·레벨 | 그대로 **경험치·레벨** | 익숙한 말이 편함 |

## 무예 (늙은 군관에게 배움)

| 무예 | 배우는 조건 | 내는 것 | 하는 일(임시) | 그림 |
|---|---|---|---|---|
| **힘껏 베기** | 레벨 2 | 30푼 + 쥐고기 5 | 앞으로 한 번 크게 벰: 데미지 2배, 밀어내기 2배, 멈춤(히트스톱) 길게. 6초마다 | 기존 휘두르기 + 궤적 굵게 |

| **휘돌려 베기** | 레벨 5 | 1냥 5전(150푼) + 쥐가죽 5 + 쥐 앞니 2 | 몸 둘레를 한 바퀴 베어 주변 몬스터를 모두 때림. 10초마다 | 4방향 휘두르기 그림을 차례로 + 원형 궤적 |

- 기력(마나) 없이 **기다리는 시간(재사용 시간)만** 둠 — 막대가 하나 늘지 않아 단순함. 나중에 무예가 많아지면 기력 도입 검토.
- 화면: 공격 버튼 둘레에 작은 무예 버튼 3개, 기다리는 동안 어둡게 + 남은 시간. 아이콘은 그림이 나오기 전까지 한자 한 글자로 대신(斬·息·旋).
- 새 그림이 필요 없음(기존 휘두르기·서 있기 그림 + 코드 연출).

## 레벨 (임시, 들쥐굴 1층 기준)

- 경험치: 들쥐 4, 큰 들쥐 15.
- 다음 레벨까지 필요: 1→2 **50**, 2→3 **110**, 3→4 **240**, 4→5 **320**. 5 이후는 들쥐굴 2~3층이 생기면 정함.
- 목표 시간(누적): 레벨 2 약 3분, 3 약 10분, 4 약 25분, 5 약 45분. 해 보고 맞춤.
- 레벨이 오르면: 최대 체력 +3, 체력 가득 회복, 레벨업 연출(글자 + 소리).
- 화면: 왼쪽 위에 레벨, 체력 막대 아래 가는 경험치 막대, 엽전.

## 가게와 회복

| 가게(사람) | 사는 것(파는 값으로) | 파는 것 |
|---|---|---|
| 주막(주모) | 쥐고기, 쌀 한 줌 | 주먹밥 5푼 — 체력 3 회복 |
| 약방(약방 영감) | 쥐수염, 쥐 앞니 | 탕약 20푼 — 체력 전부 회복 |
| 갖바치 집(갖바치) | 쥐가죽 | 짚신 (나중) |

- 가게마다 자기 물건만 사서 마을을 돌아다닐 이유를 줌. 불편하면 "어느 가게든 다 사 줌"으로 바꿀 수 있음(1차 시험 후 강콩 판단).
- 주먹밥·탕약은 가방에서 누르면 먹음. 나중에 빠른 사용 칸.
- 사람(NPC)을 누르면 창: `사기` · `팔기` · (늙은 군관은) `무예 배우기`. 팔 때는 개수 고르기.

## 길잡이 의뢰 (시간 제한 없음)

- 촌장: "곳간 뒤 쥐구멍으로 들쥐가 들끓네. 쥐고기 10개만 가져다주게." → 보상 20푼 + 주먹밥 3개, 그리고 "몸이 좀 붙으면 우물가의 늙은 군관을 찾아가 보게"(무예로 안내).
- 의뢰는 이것 하나만. 목록·지도 표시 없이 대화로만.

## 사람(NPC) 그림

- 그림이 나오기 전까지 **도포 옷 서 있기 그림을 임시로** 쓰고, 머리 위에 이름표 + 발밑 그림자. 그림은 1차 시험 뒤 Flow로 만듦.
- 아이콘: 전리품 5종 + 엽전 + 주먹밥 + 탕약은 기획 쪽이 Flow로 만들어 `assets/items/icons/`에 추가(그전엔 글자 칸).
