# 무예 합성·무기 합성 설계 v1 (2026-10-23 기획 쪽 초안 — 강콩 확인 전, 코드 아직 안 함)

바탕 결정(`mastery_fusion.md`): 2개씩만 · 성질 섞기 + 무작위(같은 조합도 사람마다 다름) · 실패 있음(엽전·재료 사라짐 + 숙련 1등급 깎임 — "적당하다" 확정) · 합성한 것도 다시 재료 · 숨은 비전(`secrets.md`). 목표는 **"나만의 무예 + 나만의 칼 = 나만의 캐릭터"**.

## 0. 공통 뼈대 (무예·무기 같은 틀)

| 규칙 | 값(임시) | 왜 |
|---|---|---|
| 재료 수 | 언제나 2개: **주**(바탕) + **부**(섞어 넣을 것) | 고르는 순서가 결과를 바꿈 → 같은 둘이라도 두 가지 길 |
| 결과 정하기 | 주의 바탕 + 부의 성질 1개 + **무작위 덧붙임 1개** | 공략표로 다 알 수 없음 |
| 무작위 | 합성할 때 만든 **씨앗 번호(seed)**로 뽑아 저장 | 저장·불러오기·나중 서버에서도 똑같이 다시 만들어짐(오류·속임 막기) |
| 결과 미리 보기 | **안 보여 줌**("?"). 성공 확률·비용만 보임 | 열어 보는 두근거림 |
| 대성공 | 5% — 덧붙임 2개 + 세기 ×1.1 | 자랑거리 |
| 세기 상한 | 같은 구간 최고 무예·무기의 **+20%까지**(넘으면 깎아 맞춤) | 판이 깨지지 않게(`secrets.md` 원칙 3과 같은 선) |
| 차수 | 합성한 것을 다시 합성 — **3차까지** | 끝없이 세지는 것을 막음 |
| 비전 | 정해진 두 개 + 정해진 조건이면 무작위 대신 이름 있는 결과 | 숨은 장치. 목록은 `secrets.md`에만 |
| 기록 | 저장 파일 `fusions`: 무엇+무엇, 씨앗, 결과, 날짜 | 나중에 "내 합성 일지"·도감 |

## 1. 무예 합성 (늙은 군관 · 「합치기」)

### 1-1. 무예마다 성질 3가지 (`data/skills.json`에 꼬리표만 더함)

| 무예 | 모양 | 기운 | 덧효과 |
|---|---|---|---|
| 힘껏 베기 | 베기(한 방) | 칼 | 밀치기 |
| 숨 고르기 | 회복 | 숨 | 회복 |
| 휘돌려 베기 | 회전 | 바람 | 끌기 |
| 삼연참 | 연속 | 칼 | 회심 |
| 질풍참 | 돌진 | 바람 | 멈칫 |
| 호통 | 주변 | 기(氣) | 멈칫 |
| 지축 가르기 | 직선 | 땅 | 밀치기 |
| 검풍 | 날림 | 바람 | 꿰뚫음 |
| 받아치기 | 자세 | 기 | 반격 |
| 회오리 베기 | 회전 | 바람 | 끌기 |
| 뇌전참 | 여러 대상 | 번개 | 멈칫 |
| 백호일섬 | 돌진 | 호랑이 | 회심 |
| 칠성검무 | 궁극 | 별 | 회심 |

- 패시브 9개는 합성 재료가 아님(늘 켜짐이라 섞을 "동작"이 없음).
- 칠성검무(궁극)는 **주로는 못 쓰고 부로만**(별 기운만 빌려줌) — 궁극이 더 세지는 것을 막음.

### 1-2. 섞는 법

1. **모양 = 주의 모양** (휘두르는 동작·판정은 주 그대로 → 코드 새로 안 만듦)
2. **기운 = 부의 기운** → 색·효과 그림(12장 중)·이름 앞 낱말이 바뀜. 예) 질풍참(주) + 뇌전참(부) = 번개 빛으로 돌진하는 "뇌전 질풍"
3. **덧효과 = 둘 중 하나**(무작위 반반)
4. **세기** = (두 무예 데미지 배율 평균) × 1.1, **기다림** = 둘 중 긴 쪽
5. **무작위 덧붙임 1개**(대성공이면 2개):

| 덧붙임 | 뽑힐 확률 | 효과 |
|---|---|---|
| 넓게 | 20% | 범위 +20% |
| 한 번 더 | 15% | 1타 더(연속·회전은 +1틱) |
| 번개 꼬리 | 10% | 맞은 적 옆 1마리에 30% 데미지 |
| 피 흡수 | 10% | 준 데미지의 5% 회복 |
| 빠른 손 | 15% | 기다림 −15% |
| 급소 | 15% | 회심 확률 +10%p |
| 없음 | 15% | (꽝 — 그래도 합성 무예) |

### 1-3. 성공·실패·비용

- 재료 조건: 두 무예 모두 **숙련 5등급 이상**(숙련이 먼저 있어야 함 → 순서는 아래 4).
- 성공 확률 = 60% + (두 무예 숙련 등급 합 − 10) × 2%, 최대 90%. (둘 다 5등급 = 60%, 둘 다 10등급 = 80%)
- 비용: 엽전(주 무예 배울 값 × 2) + **우두머리 재료 1개**(아무 우두머리나).
- **결과 = 1번(주) + 2번(부) → 새 무예 3번**(2026-10-23 강콩 확정).
- **3번의 숙련**(2026-10-23 강콩 두 안을 합침): 새 무예라 **새로 쌓음**(1등급부터), 대신 **1번(주) 무예가 쌓은 숙련 횟수의 10%를 이어받음**. 예) 1번이 10등급(900번) → 90번을 안고 시작 = 3등급 조금 넘음. 3번을 다시 합성 재료로 쓰려면 5등급(200번)까지 직접 키워야 함 → 합성의 합성이 너무 빨리 되지 않게 막아 줌(차수 상한과 같은 역할).
- **성공하면 1번(주)만 남고 2번(부)은 사라짐**(2026-10-23 강콩 확정). 1번은 숙련 1등급 깎임.
- **실패하면** 엽전·우두머리 재료가 사라지고 1번·2번 숙련이 1등급씩 깎임. 두 무예 모두 남음(10-22 "아픔 적당" 그대로).
- **무예 트리는 "배운 적 있음" 기록으로 봄**: 지금 트리는 "가지고 있는 무예"로 앞 무예를 검사함 → 2번이 사라지면 2번을 앞 무예로 둔 다음 무예를 못 배우게 됨(예: 질풍참을 재료로 쓰면 백호일섬을 못 배움). 그래서 저장 파일에 `skillsEverLearned`(한 번이라도 배운 무예)를 두고 트리 검사는 이것으로 함. 무예가 늘어나는 것(10개 → 11개)은 트리와 상관없음 — 끊기는 것은 **앞 무예가 사라질 때뿐**.
- **사라진 2번은 다시 배울 수 없음**(2026-10-24 강콩 확정): 3번 안에 1번과 2번이 함께 섞여 있는 것이고 이름에만 안 보일 뿐 → 늙은 군관 목록에서 "3번에 들어감"으로 흐리게 보이고 배우기 막힘. 트리 검사는 `skillsEverLearned` 기록으로 하므로 2번 다음 무예는 그대로 배울 수 있음.
- 그래서 합성 창에서 **한 번 더 묻기**: 「○○(2번)은 △△(3번) 안으로 들어가 다시 배울 수 없습니다. 합칠까요?」 — 실수로 아끼는 무예를 잃지 않게.

### 1-4. 이름·아이콘·연출 (그림 새로 안 만듦)

- 이름 = 기운 낱말 + 주 무예의 짧은 이름. 기운 낱말: 칼 "예검"·바람 "풍"·번개 "뇌전"·땅 "지축"·별 "칠성"·호랑이 "백호"·숨 "청기"·기 "기합". 예) "뇌전 질풍", "백호 회오리". 플레이어가 **6자 안에서 이름 바꾸기** 가능.
- 아이콘 = 두 무예 아이콘을 **반씩 잘라 붙이고 옥빛 테두리**(코드로). 3차 합성은 테두리 금빛.
- 연출 = 주 무예 연출 + 부 기운의 효과 그림(fx 12장)과 색을 겹침.
- 합성 장면: 두 아이콘이 소용돌이로 돌며 합쳐짐 → 성공은 금빛 터짐 + 이름 붓글씨, 대성공은 별빛 추가, 실패는 먹물 번짐 + 낮은 소리.
- 합성 무예는 최대 **6개**까지 가짐(무예창 칸). 버릴 수 있음.

## 2. 무기 합성 (대장장이 · 「합치기」)

### 2-1. 섞는 법 — **그림은 주 무기 그대로**(그림 부담 없음)

- 주 무기: 모양·그림·기본 공격력 그대로.
- 부 무기: **사라짐**(재료). 부 무기의 "성질" 1개를 주 무기에 **새김**:
  - 무기 성질 = 고유 연출(`fx`: 휘두를 때 흩날림 `trailParticles`, 맞힐 때 `hitFx` — 예: 여우불 검의 여우불, 흑웅 대검의 금빛 발톱) 중 하나, 또는 **기운**(아래 2-3).
- 무작위 덧붙임 1개: 공격력 +5~10% / 회심 +5%p / 휘두르기 빠르게 −8% / 사거리 +6 / 꽝.
- 새김 칸은 **무기 한 자루에 2칸**. 꽉 차면 새로 새길 때 어느 칸을 바꿀지 고름 → 차수 상한 역할.
- 이름: 새긴 성질이 이름 앞에 붙음. 예) "여우불 깃든 사인검". 궤적 색은 두 무기 색을 섞음.

### 2-2. 성공·실패·비용

- 성공 확률 = 70% − (두 무기 구간 차 × 5%), 최소 40%. (비슷한 구간끼리가 잘 붙음)
- 비용: 엽전(주 무기 값의 30%) + 그 구간 전리품 5개.
- 실패: **부 무기와 엽전·전리품만 사라짐**, 주 무기는 그대로(아끼는 칼이 망가지면 너무 아픔).

### 2-3. 무예와 무기를 잇는 고리 — **기운 맞춤**

- 무기에도 기운이 있음(새기거나, 원래 무기 기운: 여우불 검=불꽃(여우불), 청풍검=바람, 북두 장검·칠성검=별, 사인검·백호=호랑이 …).
- **무예 기운 = 무기 기운이면 그 무예 데미지 +15%**, 효과 그림도 한 겹 더. → 합성 무예 + 합성 칼의 조합을 찾는 재미 = "나만의 캐릭터"가 숫자로도 보임.

## 3. 숨은 장치 후보 (강콩이 고름 — 정하면 `secrets.md`로)

- 무예 비전: "백호일섬(주) + 칠성검무(부)를 둘 다 숙련 10에서" → 「칠성백호」(이름 있는 무예, 효과 그림 2장 겹침).
- 무기 비전: "사인검 + 칠성검을 성황당 앞에서 합치면" → 「사인참사검」(실제 조선의 사인검 이야기에서). 
- 실패 속 행운: 실패할 때 0.5%로 "이상한 무예"(엉뚱하지만 쓸모 있는 것) — 실패도 기대하게.

## 4. 만드는 순서 (그림 없이 코드만으로 됨)

1. **무예 숙련**(등급 1~10, `mastery_fusion.md` 숙련 제안 v1의 무예 줄) — 합성의 재료 조건
2. 무예 합성(1)
3. 무기 합성(2) + 기운 맞춤(2-3)
4. 비전·이상한 무예(3) — 강콩이 고른 것만
5. 능력치 숙련·수련 나무(`secrets.md` 3)는 그 뒤

각 단계마다 자동 시험: 같은 씨앗 → 같은 결과, 세기 상한, 차수 상한, 실패 비용, 저장 → 불러오기.
