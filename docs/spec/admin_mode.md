# 관리자 모드 (2026-10-16 초안 — 강콩 확인 필요)

## 왜

강콩: "관리자 모드가 코드에 적용 안 된 것 같다." 확인해 보니 **저장소 코드·문서·개발 계획서 어디에도 관리자 모드 규격이 없었음**(전달이 빠진 것). 그래서 이 파일로 처음 정함. 목적은 시험을 빠르게 하는 것 — 레벨·장비·맵을 바로 바꿔 새 내용(새 굴·쥐왕·족제비·새 무기·옷 무기 자세)을 확인.

시험 배율(`test_boost.md`)과는 다름: 시험 배율은 "평소처럼 하되 빨리", 관리자 모드는 "원하는 상태로 바로 건너뛰기".

## 들어가는 법 (아이폰에 키보드가 없으므로 터치로)

- 왼쪽 위 상태 칸의 **레벨 글자를 2초 안에 5번** 누르면 관리자 창이 열림. PC는 **F2**도 됨.
- `data/game.json`에 `"admin": { "enabled": true }`. 나중에 남에게 보여 줄 때는 `false`로 끄면 들어가는 길이 아예 없어짐.
- 관리자 모드가 켜져 있는 동안 화면 왼쪽 위에 작게 **"관리자"**(빨강 흐린 글씨).

## 관리자 창 (화면 가운데, 탭 4개)

| 탭 | 기능 |
|---|---|
| 나 | 레벨 정하기(1~15, − / + 단추), 경험치 +100 / +1000, 엽전 +1냥 / +10냥, 체력 가득, **안 죽기** 켜기/끄기, **한 방** 켜기/끄기(몬스터가 한 대에 쓰러짐), 무예 모두 배우기(재료·엽전 없이) |
| 물건 | `data/items.json`의 모든 물건 목록(아이콘 + 이름, 종류별로 묶음). 누르면 가방에 1개, 길게 누르면 10개. 무기·옷은 레벨 제한을 무시하고 바로 끼기 단추도 |
| 맵 | 모든 맵 목록(마을·들쥐굴 1~3층·족제비굴). 누르면 그 맵의 시작 자리(`spawn`)로 바로 이동. 지금 맵의 몬스터 모두 다시 생기게, 쥐왕 바로 생기게 |
| 설정 | 시험 배율 켜기/끄기·배율 숫자(경험치·엽전·전리품), 의뢰 처음부터, 격자 편집 열기(지금 있는 G 기능), **저장 지우고 새로 시작**(두 번 확인) |

## 규칙 (Claude Code)

1. 관리자 기능은 **규칙 쪽(`src/core/`)의 보통 함수를 부르기만** 함(레벨 정하기 = `progress`, 물건 주기 = `equipment`, 이동 = 맵 바꾸기). 관리자 전용 규칙을 따로 만들지 않음 — MMO 때는 서버 명령으로 바꾸면 됨.
2. 창은 `src/ui/adminPanel.js` 하나에.
3. **안 죽기·한 방은 저장하지 않음**(다시 열면 꺼짐). 레벨·물건·엽전 변화는 보통처럼 저장됨.
4. 레벨을 정하면 그 레벨의 최대 체력·데미지 보너스로 바로 바뀜, 레벨업 연출은 띄우지 않음(여러 번 누를 때 시끄러우므로).
5. 반영하면 이 파일 아래에 "반영됨" 적기.
