# 시험 배율 (2026-10-16 강콩) — 진행 속도는 지금은 검증용, 밸런스는 나중에

## 왜

레벨이 오를수록 진행이 느려짐(강콩 아이폰 시험). 지금 표 그대로면 레벨 15까지 약 **1,030마리**를 잡아야 함(들쥐 181 → 굴 들쥐 439 → 족제비 411, 계산은 아래). 지금 단계의 목적은 "내용이 다 돌아가는지"(새 굴·쥐왕·족제비·새 무기·대장장이·무예) 확인이므로, 진행을 빠르게 하고 **밸런스(재미있는 속도)는 콘텐츠가 다 붙은 뒤 따로 조정**하기로 함.

## 방식 — 표는 그대로, 배율만 따로

- `data/economy.json`의 레벨 표·`data/monsters.json`의 경험치·엽전·드랍 확률은 **고치지 않음**(나중 밸런스 조정의 기준값).
- 대신 `data/game.json`에 `testBoost` 하나를 둠. 끄면(`enabled: false`) 원래 표 그대로.

```json
"testBoost": {
  "_설명": "시험 배율(docs/spec/test_boost.md). 진행 검증용 — 밸런스 조정 때 끔. exp=얻는 경험치, coins=떨어지는 엽전, dropChance=전리품이 떨어질 확률(곱한 뒤 최대 1), 개수는 그대로",
  "enabled": true,
  "exp": 3,
  "coins": 2,
  "dropChance": 1.5
}
```

| 값 | 배율 | 이유 |
|---|---|---|
| 경험치 | ×3 | 레벨 15까지 약 1,030마리 → 약 350마리 |
| 엽전 | ×2 | 새 무기(80푼·2냥·5냥)를 시험 중에 살 수 있게 |
| 전리품 확률 | ×1.5 (최대 100%) | 무쇠 환도 재료(쥐가죽 5)·청강 환도 재료(황모 2)를 모을 수 있게. 황모 6% → 9% |

## Claude Code가 할 일

1. 배율은 **규칙 쪽(`src/core/`)에서 곱함** — 몬스터를 쓰러뜨려 경험치·엽전·드랍을 정하는 곳 한 군데. 화면 코드에서 곱하지 않음(MMO 때 서버로 옮길 곳이 같아야 함).
2. 곱한 경험치·엽전은 반올림(최소 1). 확률은 `min(1, chance × dropChance)`.
3. 켜져 있으면 화면 왼쪽 위 체력바 아래에 작게 **"시험 ×3"**(흐린 글씨)를 띄움 — 켜 둔 것을 잊지 않게.
4. 쥐왕 보상·의뢰 보상도 같은 배율(경험치·엽전만).
5. 반영하면 이 파일 아래에 "반영됨" 적기.

## 나중에 (밸런스 조정 때)

- `enabled: false`로 끄고, 그때 레벨 표·경험치를 바로 고침. 이미 레벨이 오른 저장 파일은 그대로 둬도 됨(레벨이 내려가지 않음).
- 이번 시험에서 확인한 것은 "내용이 돌아가는지"뿐 — **"재미있는 속도"는 확인한 것이 아님**. 밸런스 조정 때 처음부터 다시 봐야 함.
