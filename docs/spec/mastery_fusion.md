# 숙련과 무예 합성 — 방향 (2026-10-22 강콩 결정, 세부 설계 전)

코드는 아직 하지 않음. 세부 설계(숫자·화면)를 강콩과 정한 뒤 Claude Code에 넘김.

## 결정

- **숙련**: 많이 쓸수록 세짐. 세 가지에 모두 둠.
  - 무예 숙련: 같은 무예를 쓸수록 등급이 오름(데미지·범위·기다림이 좋아짐) → 낮은 무예(힘껏 베기 등)도 끝까지 쓸모 있음.
  - 무기 숙련: 칼 종류를 오래 쓸수록(맞힌 횟수) 그 칼이 세짐 — 계획서의 "손때"와 같은 뿌리.
  - 능력치 숙련: 하는 일에 따라 능력치가 오름(맞을수록 체력·방어, 때릴수록 힘, 걸을수록 걸음 등).
- **무예 합성**: **2개씩만** 합침 → 새 "나만의 무예"가 생김. **실패할 수 있음.** 합성한 무예도 다시 연계·합성 재료가 될 수 있어 경우의 수가 늘어남.
- 연계 무예(정해진 6~8개)는 합성으로 대신함(기각 아님, 합성 설계 때 다시 봄).

## 정할 것 (다음 기획 대화)

- 합성 결과를 정하는 방식: (가) 두 무예의 성질(모양·속성·효과)을 섞는 규칙으로 자동 생성 / (나) 미리 만든 조합표(13×12/2 = 78쌍)에서 나옴 / (다) 둘을 섞되 무작위 덧붙임(같은 조합도 사람마다 다름).
- 실패하면: 재료 무예 숙련이 깎임 / 엽전·재료만 사라짐 / 이상한 무예(약한 무예)가 나옴.
- 합성 재료: 숙련 등급 몇 이상, 엽전·전리품, 어디서(늙은 군관·성황당).
- 합성 무예의 이름·아이콘·연출: 두 무예의 효과 그림을 섞어 코드로 만듦(그림 12장 재사용).
- 숙련 숫자: 등급 수(예: 1~10), 오르는 속도, 능력치 숙련이 레벨 오름과 어떻게 나뉠지.

## 비슷한 게임 (2026-10-22 찾아봄)

- 검은사막(한국 2017): "라밤의 깨달음" — 무예 2개를 골라 하나를 없애고 둘이 섞인 새 무예를 얻음, 레벨 56부터. 실패 이야기는 기사에 없음.
- 라이좀: 무예 요소(정확도·추가 데미지 등)를 이어 붙여 나만의 동작을 만듦(쓸 때 비용이 커짐).
- 같은 구조(2개 합성 + 실패 + 합성 무예의 재합성)를 그대로 쓰는 게임은 찾지 못함 — 다만 모든 게임을 다 본 것은 아니라 "없다"고 단정할 수는 없음(확인 필요).
