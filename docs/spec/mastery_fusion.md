# 숙련과 무예 합성 — 방향 (2026-10-22 강콩 결정, 세부 설계 전)

코드는 아직 하지 않음. 세부 설계(숫자·화면)를 강콩과 정한 뒤 Claude Code에 넘김.

## 결정

- **숙련**: 많이 쓸수록 세짐. 세 가지에 모두 둠.
  - 무예 숙련: 같은 무예를 쓸수록 등급이 오름(데미지·범위·기다림이 좋아짐) → 낮은 무예(힘껏 베기 등)도 끝까지 쓸모 있음.
  - 무기 숙련: 칼 종류를 오래 쓸수록(맞힌 횟수) 그 칼이 세짐 — 계획서의 "손때"와 같은 뿌리.
  - 능력치 숙련: 하는 일에 따라 능력치가 오름(맞을수록 체력·방어, 때릴수록 힘, 걸을수록 걸음 등).
- **무예 합성**: **2개씩만** 합침 → 새 "나만의 무예"가 생김. **실패할 수 있음.** 합성한 무예도 다시 연계·합성 재료가 될 수 있어 경우의 수가 늘어남.
- 연계 무예(정해진 6~8개)는 합성으로 대신함(기각 아님, 합성 설계 때 다시 봄).

## 결정 2 (2026-10-22 22:18 강콩)

- 합성 결과 방식은 **(다) 성질 섞기 규칙 + 무작위 덧붙임** — 같은 조합도 사람마다 결과가 다름.
- **숨은 비밀**을 곳곳에 둠(「99강화 나무몽둥이」처럼 아무도 모르는 장치·무예). 목록은 `docs/spec/secrets.md`.
- **무기 합성도 나중에** 같은 방식으로 → 무예 + 무기로 "나만의 캐릭터".
- 그림·연출은 강콩이 만들어 줌 → 기획 쪽은 필요한 그림을 프롬프트로 먼저 줌.

## 합성 설계 제안 v1 (기획 쪽 초안 — 강콩 확인 전, 코드 아직 안 함)

1. **성질 3가지**: 무예마다 `모양`(베기·직선·원·돌진·날림·연속·자세·회복), `기운`(칼·바람·번개·땅·별·호랑이·숨), `덧효과`(멈칫·끌기·회심·반격·밀치기·회복) 꼬리표를 붙임(`data/skills.json`).
2. **섞는 규칙**: 먼저 고른 무예(주)의 `모양` + 둘째 무예(부)의 `기운` + 덧효과 둘 중 하나. 세기는 둘의 평균 ×1.1, 기다림은 둘 중 긴 쪽.
3. **무작위 덧붙임**: 합성할 때 1개를 뽑음(범위 +, 연속 +1, 번개 꼬리, 피 흡수, 기다림 −, 아무것도 없음 등). 뽑기는 저장된 `seed`로 하여 저장·불러오기·나중 서버에서 똑같이 다시 만들 수 있게.
4. **성공·실패**: 기본 성공 60% + 두 무예 숙련 등급만큼 더함(최대 90%). 실패하면 재료 무예는 남고 엽전·재료만 사라지고 두 무예 숙련이 1등급 깎임. 드물게(5%) **대성공** — 덧붙임 2개.
5. **재합성**: 합성 무예도 재료가 됨. 대신 **차수 상한 3**(합성의 합성의 합성까지), 차수마다 세기 상한을 둠 → 끝없이 세지는 것을 막음.
6. **비전(숨은 무예)**: 정해진 두 무예를 정해진 조건(예: 둘 다 숙련 최고 + 성황당에서)으로 합성하면 무작위 대신 이름 있는 무예가 나옴. 조건은 `secrets.md`에만.
7. **이름·모습**: 이름은 기운 + 모양 낱말로 자동("뇌전 회오리 베기"), 플레이어가 6자 안에서 고칠 수 있음. 연출은 두 무예의 효과 그림(12장)을 겹치고 색을 섞음 → 새 그림 없이도 됨.
8. **어디서**: 늙은 군관(합성은 숙련 등급 5 이상 무예만). 비용은 엽전 + 우두머리 재료.

## 정할 것 (다음 기획 대화)

- 위 제안 v1 확인(특히 4 실패 벌칙, 5 차수 상한).
- 합성 결과를 정하는 방식(→ 결정 2에서 (다)로 정함): (가) 두 무예의 성질(모양·속성·효과)을 섞는 규칙으로 자동 생성 / (나) 미리 만든 조합표(13×12/2 = 78쌍)에서 나옴 / (다) 둘을 섞되 무작위 덧붙임(같은 조합도 사람마다 다름).
- 실패하면: 재료 무예 숙련이 깎임 / 엽전·재료만 사라짐 / 이상한 무예(약한 무예)가 나옴.
- 합성 재료: 숙련 등급 몇 이상, 엽전·전리품, 어디서(늙은 군관·성황당).
- 합성 무예의 이름·아이콘·연출: 두 무예의 효과 그림을 섞어 코드로 만듦(그림 12장 재사용).
- 숙련 숫자: 등급 수(예: 1~10), 오르는 속도, 능력치 숙련이 레벨 오름과 어떻게 나뉠지.
