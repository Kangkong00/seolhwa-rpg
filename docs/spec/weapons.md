## 무기 `assets/weapons/<id>.png` (2026-10-10 시작)

- 무기는 물건만 따로 그린 그림 1장. 캐릭터 손에 코드로 붙여 휘두르고, 같은 그림을 가방 아이콘·바닥 아이템으로도 씀(작게 줄여서).

- 목검 3종(2026-10-10 합격): `wood_pine` 1-1 소나무 목검(첫 무기, 길이 480), `wood_oak` 1-2 참나무 목검(500), `wood_bakdal` 1-3 박달나무 목검(520). 길이는 캐릭터 키 640 기준, 단계가 오를수록 조금씩 길게(강콩 확인 필요). 원본 `assets/source/weapon_<id>.png`.
- **휘두르기 자세 (홑옷만 있음, 2026-10-10)**: `outfit1_hotot/{front,side,back}_raise.png`(치켜들기), `{front,side,back}_strike.png`(내려치기). 손은 빈 주먹, 무기는 코드가 붙임. **캔버스 640×720, 발 y=700, 몸통 가운데 x=320**(주먹 그림과 같은 규칙). 옆면은 왼쪽을 봄(오른쪽은 반전, 주먹 x는 640−x, 각도는 부호 반대).
- **무기는 들고 있는 동안 늘 보임(2026-10-10 강콩)**: 서 있기·걷기에도 손에 쥐고 있음. 휘두를 때만 나타나면 안 됨.
- **휘두르기 궤적은 실제와 비슷하게 (2026-10-10 강콩: 정면·뒷면이 이상함)**. 원인: 정면·뒷면에서 무기를 화면 평면에서 돌려서 옆으로 반원을 그렸음. 실제로는 정면에서 보면 칼이 머리 위에서 **화면 쪽으로 다가오며 짧아졌다가(칼끝이 보는 사람을 향함) 아래로 다시 길어짐**. 옆면만 반원이 맞음. 그래서 **무기 방향을 3D로 계산해 화면에 투영**함(기획 쪽에서 합성 시안으로 확인함 — `docs/swing_grip.gif`):
  - 무기 방향 각도 θ: 0 = 칼끝이 위, 90 = 칼끝이 바라보는 쪽(앞), 180 = 아래, 음수 = 머리 뒤. `lat` = 옆으로 기운 정도(대각선 베기).
  - 3D 방향: 위 Y = cos θ, 앞 F = sin θ, 옆 X = lat.
  - 화면 방향 (sx 오른쪽+, sy 아래+), 깊이 줄임 K = 0.5:
    - 정면(아래를 봄): sx = X, sy = −Y + K·F. F < 0(칼이 머리 뒤)이면 몸 뒤에 그림.
    - 뒷면(위를 봄): sx = −X, sy = −Y − K·F. F > 0(칼이 몸 앞, 화면 안쪽)이면 몸 뒤에 그림.
    - 옆면(왼쪽을 봄): sx = −F, sy = −Y. F < 0이면 몸 뒤. 오른쪽은 반전.
  - 무기 그림은 화면 각도 atan2(sx, −sy)로 돌리고, **세로 길이를 √(sx²+sy²)배**로 줄임(1보다 크면 1). 쥐는 점 (120,800)이 회전·줄임의 중심.
  - 휘두르기: θ를 **−40 → 125**로(정면·뒷면 `lat` 0.15, 옆면 0), 처음엔 느리고 끝으로 갈수록 빠르게. 몸 그림은 3단계 `raise` → `swing` → `strike`(아래 "휘두르기 3단계" — 처음 2단계였다가 "팔만 따로 노는 느낌"으로 바꿈). **쥐는 점은 항상 지금 보이는 몸 그림의 주먹에 고정**(주먹 사이를 보간하면 칼이 손에서 떨어져 보임 — 시안에서 확인). 맞힘 판정은 칼이 앞을 지날 때(θ 약 60~90).
  - **궤적 모양은 칼끝을 따라가지 않고 정해 둔 모양으로 그림 (2026-10-11 강콩: 모든 방향에서 번개 모양으로 보임)**. 원인: 칼끝 경로를 그대로 이으면 몸 그림이 raise → strike로 바뀌며 쥐는 점이 순간 이동하는 곳에서 꺾임. 기획 쪽 시안 `docs/trail_side.png`(옆면), `docs/trail_mock.png`(정면·뒷면 위치). 좌표는 640×720 몸 그림 기준(캔버스 밖으로 나가도 됨):

## 휘두르기 3단계·몸 움직임·외곽선 (2026-10-11, 반영됨)

- **휘두르기 3단계**: 몸 그림을 `raise` → `swing`(새 그림 `{front,side,back}_swing.png`, 손 덮개 `_swing_hand.png`) → `strike`. θ < 5 raise, 5 ≤ θ < 80 swing, θ ≥ 80 strike(`data/weapons.json` `swing.poseSwingTheta`·`poseStrikeTheta`). 쥐는 점은 늘 지금 보이는 그림의 주먹 — swing 주먹: front (184,210), side (116,224), back (456,210)(`attach.outfit1_hotot.swing`). 손 덮개 순서는 그대로. 시안 `docs/swing_3frame.gif`. swing 그림이 없는 옷·방향은 raise 그림으로 대신함.
- **몸 전체 움직임**: 휘두르기 직전 `preMs` 60ms 동안 바라보는 반대쪽으로 `backPx` 6 뺌(칼은 치켜든 채) → 진행 30~80% 동안 바라보는 쪽으로 내딛기(640 기준 옆면 10, 정면·뒷면 6) → 끝나면(`recoverMs`) 제자리. 몸·무기·손 덮개·그림자를 함께 옮기는 화면상 움직임(실제 위치는 그대로). 값은 `swing.lean`. 맞힘 판정·궤적·소리 타이밍은 칼이 돌기 시작한 뒤 기준(직전 60ms만큼 늦게 맞음).
