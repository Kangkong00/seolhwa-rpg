# 캐릭터 그림·걷기·주먹·그림자

> 캐릭터 그림 규격, 걷기 애니메이션, 주먹 지르기, 발밑 그림자. CLAUDE.md의 목차에서 연결됨. 내용을 고칠 때는 이 파일에서 해당 부분만 고치고, 파일 전체를 다시 쓰지 않음.

## 캐릭터 `assets/characters/outfitN_이름/`

| 옷 | 폴더 |
|---|---|
| 1 허름한 홑옷 (시작 모습) | `outfit1_hotot` |
| 2 무명옷 | `outfit2_mumyeong` |
| 3 도포 | `outfit3_dopo` |
| 4 철릭 | `outfit4_cheollik` |
| 5 두정갑 | `outfit5_dujeonggap` |
| 6 신선복 | `outfit6_sinseon` |

- 모든 PNG는 **투명 배경, 400×720 캔버스, 발끝 기준선 y=700, 가로 가운데 정렬**. 정면 서 있기 키를 640px로 맞춰 옷 사이 크기가 같음.
- 파일: `front.png`, `side.png`(왼쪽을 봄), `back.png` = 서 있기 / `front_step.png`, `side_step.png`, `back_step.png` = 걷기 자세.
- **오른쪽 방향은 `side*`를 좌우 반전**해서 씀.
- 옷 6종 모두 서 있기 3장 + 걷기 자세 3장이 갖춰져 있음.
- 옷 목록과 다리 반전 기준선은 `data/outfits.json`(`legSplitY`)에서 관리. 2026-10-09에 옷 2~6의 `*_step.png`가 새 그림으로 교체되어 `legSplitY`를 다시 확인함(무명옷 590, 도포 592, 철릭 612, 두정갑 600, 신선복 600 — 기획 쪽 측정값이 옷자락 끝과 맞아 그대로 적용).

## 걷기 애니메이션 방식 (검증 완료)

- 프레임 순서: `step` → `stand` → `step(다리 반전)` → `stand`, 약 180ms 간격.
- **정면·뒷면의 반대 발**: `step` 그림에서 `data/outfits.json`의 `legSplitY` 아래(옷자락 아래) 다리 부분만 몸 중심선 기준으로 좌우 반전하고, 그 위에 상체를 다시 얹음. 런타임에 처리하거나 빌드 시 미리 만들어도 됨.
- **옆면**: `side_step`과 `side`를 번갈아 씀(다리 반전 안 함).
- 걷기 자세 프레임에서 몸을 약 3~6px 띄워 걷는 리듬을 줌.

## 주먹 지르기 (2026-10-10 추가, 옷 6종 모두)

- 시작은 맨몸이라 첫 공격은 주먹(2026-10-10 강콩). 파일: `front_punch.png`, `side_punch.png`(왼쪽을 봄), `back_punch.png`. 오른쪽은 `side_punch` 좌우 반전.
- **캔버스가 서 있기와 다름: 640×720**(뻗은 팔이 400을 넘어서). 발끝 기준선 y=700은 같고, **몸통(허리 부분) 가운데가 x=320**. 서 있기(400 폭, 가운데 x=200)와 겹칠 때는 몸 가운데끼리 맞추면 됨(= punch를 x로 −120 옮긴 것과 같음). 크기는 정면 주먹 그림 키를 640으로 맞춤(옆면은 다리를 벌려 조금 낮음, 정상).
- 동작 제안: `stand` → `punch`(약 150ms 유지, 바라보는 쪽으로 2~4px 내딛기) → `stand`. 시간·내딛는 거리는 `data/`에. 번쩍임·몬스터가 맞고 흔들림·숫자는 그림에 없고 코드로 붙임. 정면·뒷면 주먹은 옷마다 뻗는 팔이 다름(좌우 통일 안 됨, 옷 여밈 방향 때문에 반전하지 않음).
- 원본: `assets/source/outfitN_이름_punch.jpg`. 철릭·두정갑은 신발에 걸친 Flow 워터마크를 지운 뒤 오림.
- **반영됨(2026-10-10)**: 오른쪽 아래 `공격` 버튼(PC는 스페이스, 누르고 있으면 공격 간격마다 반복). `stand` → `punch`(150ms, 바라보는 쪽으로 3px 내딛기) → `stand`. 주먹 그림과 서 있기 그림 모두 캔버스 가로 가운데(0.5)를 기준점으로 그려 몸 가운데가 겹침. 주먹 지르는 동안은 걷지 않음.

## 그림자

- **필수, 고정 (2026-10-10 강콩: 카메라 1.0배와 함께 게임의 핵심).** 캐릭터·몬스터 발밑에 반투명 타원 그림자. `data/game.json`의 `shadow`: 주인공은 `player.width`/`height`/`alpha`(맵 픽셀), 몬스터는 표시 키에 비례(`monster.widthRatio`/`heightRatio`/`alpha`), 가장자리 흐림 `softness`. 몬스터에도 붙어 있음(`src/scenes/MonsterView.js`).
