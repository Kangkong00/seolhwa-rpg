# 2026-11-10 강콩 요청 3가지 (Claude Code가 바로 반영)

강콩: ① 그래픽을 작은 단위로 — 사람이 나무 뒤로 가도 나뭇잎 정도만 가려지게 ② 무기 휘두르는 모습·애니메이션을 더 자연스럽고 화려하게 ③ 숨은 버그·고칠 곳을 찾아 고치기.

## 1. 물건 뒤에서 캐릭터가 통째로 사라짐 → 가려지면 비쳐 보이기

- 확인한 것(12곳 찍기 `docs/fx_check/occlusion_before_1110.jpg`):
  - 마을 조각은 이미 361개로 픽셀 단위까지 오려져 있고, 큰 나무도 여러 조각(기준선 600·656·720)으로 나뉘어 있음.
  - 문제는 조각 크기가 아니라, 줄기·지붕 바로 뒤에 서면 몸 전체가 사라져 체력바만 보이는 것.
- 해 본 것(버림): 조각을 세로 띠로 더 잘게 나누고 바깥으로 뻗은 잎·처마 끝의 기준선을 당기는 도구를 만들어 봄. 화면이 거의 그대로였고 담에 세로 줄무늬가 생겨 지움.
- 반영한 것 `OcclusionFade`(`src/scenes/mapObjects.js`, 값 `data/game.json` `occlusionFade`):
  - 내 캐릭터 몸을 **실제 픽셀로 덮은 앞 조각만** 0.16초에 걸쳐 alpha 0.45로 반투명하게 함. 캐릭터가 벗어나면 되돌아옴.
  - 조각 아래 바닥 그림에 같은 물건이 그려져 있어 물건 모양은 그대로이고, 그 사이에 선 캐릭터만 비쳐 보임(`docs/fx_check/occlusion_after_1110.jpg`).
  - 덮는지는 몸 표본 점 18개(가로 3 × 세로 6)를 조각의 불투명 지도(맵 2px 한 칸, 처음 필요할 때 한 번 만듦)에 대어 봄. 조각 네모만 겹치는 것으로는 흐려지지 않음.
  - 몬스터·NPC는 예전처럼 가려짐. 그림 파일·기획 쪽 조각은 손대지 않음.
  - `enabled: false`면 예전처럼 완전히 가려짐.
- 확인 필요(강콩): "잘게 자르기"를 이 방식으로 풀었음. 잎 조각만 따로 앞뒤가 바뀌는 식을 원하면 조각 그림을 다시 만들어야 함(기획 쪽).

## 2. 무기 휘두르기 — 더 자연스럽고 화려하게

- 찍어 본 것: 내려친 뒤 대기 자세로 뚝 끊겨 돌아가고, 궤적이 금방 사라짐.
- 반영(`data/weapons.json` `swing.settle`·`swing.smear`·`swing.dust`·`trail.glowAlpha`, `data/game.json` `swingFx.trailMs`):
  - **끝 동작(settle)**: 휘두르기가 끝난 뒤 0.15초 동안 내려친 자세(125° → 100°) → 휘두르는 자세(70° → 16°) → 대기 자세(20°)로 부드럽게 이어짐. 다음 공격·무예·걷기를 시작하면 바로 끊겨 공격 속도는 그대로(`MapScene.updateSettle`). 삼연참처럼 이어 치는 중에는 없음.
  - **칼 잔상(smear)**: 휘두르는 빠른 구간에 칼 그림이 한 장씩 남았다 0.11초에 흐려짐(동시에 4장쯤).
  - **궤적 빛 겹**: 같은 궤적을 더하기 섞기로 한 번 더(alpha 0.5) → 속이 밝게 빛남. 남는 시간 250 → 320ms.
  - **발밑 먼지(dust)**: 내려치는 순간 발 앞에서 먼지 5덩이가 바라보는 쪽으로 퍼짐(그림 하나).
  - 값을 0으로 두면 각각 꺼짐. 찍기 `docs/fx_check/swing_1110.jpg`.
- 시험: 끝 동작 각도 흐름(125 → 100 → 65 → 16 → 대기 20), 끝 동작 중 다시 공격하면 바로 새 휘두르기, `swingsync`(옷 6 × 방향 3) 문제 없음.

## 3. 찾아 고친 버그

| 찾은 것 | 원인 | 고침 |
|---|---|---|
| 휘두르는 도중 맵을 옮기면 궤적 그림(캔버스 텍스처 `trail:N`)이 남음 → 오래 하면 메모리가 조금씩 참 | 장면이 끝나면 흐려지는 tween이 끊겨 `destroy`가 안 불림 | `SwingTrail`이 장면 `shutdown`에서 스스로 지움(6번 옮겨 0개 남는 것 확인) |
| 끝 동작 상태가 맵을 옮긴 뒤 남을 수 있음 | 장면 다시 시작은 같은 객체 | `create`에서 `settle` 비움 |

- 점검했으나 문제 없던 것:
  - 맵 6번 오가기: 이벤트 수 그대로(pointerdown 2·resize 4·shutdown 15), 화면 물체 수 그대로.
  - 무예(휘돌려 베기·받아치기·칠성검무)·평타 도중 쓰러짐 → 체력 가득·동작·어둠·단추 모두 정상.
  - 20개 맵 모두 열기·가방·무예창: 콘솔 오류·경고 0.
  - 전체 시험(mastery·items·mapcheck·swingsync·skilldmg·smoke·actionpad·skillslots·masteryplay·earthsplit·screenfill·itemsplay·monsterwalls) 문제 없음, 무작위 시험 씨앗 11·12 오류·NaN·감시 경고 0.
- 알려진 것(버그 아님, 그림 대기): 가방을 열 때 약·술 아이콘 6개(`med_insam`·`med_nogyong`·`med_sansam`·`drink_takju`·`drink_yakju`·`drink_songsun`)와 `fx_t3_*` 13개가 404 — Flow 139~142가 오면 사라짐(그 전엔 글자 아이콘·빛살로 대신).
- 눈에 띈 것(안 고침, 판단 필요): 맵을 옮길 때마다 주인공 옷 그림 텍스처를 다시 만듦(`outfit1_hotot@N`). 새는 것은 아니지만 맵 이동이 느린 까닭일 수 있음.
