# 2026-10-31 강콩 피드백 (아이폰 화면 `docs/shot_1031_iphone.png`)

## 1. 화면 아래가 잘림 — 아래 약 1/8이 검은 띠 (10-24 고침 뒤에도 남음)

- 화면 찍기(2000×924): 게임 그림·조이스틱·단추가 모두 위 812px 안에 있고, 아래 112px(약 52pt)가 바탕색(#1d1a14) 띠. → 캔버스뿐 아니라 **화면 글자(조이스틱·단추)까지 함께 위로 올라가 있음** = 페이지가 쓰는 화면 높이 자체가 실제 화면보다 작음.
- 10-24 고침(c8d2767)은 캔버스를 `#game` 크기에 맞춤. 그런데 `#game`(`position: fixed; inset: 0`)이 아이폰 사파리에서 **작은 화면 높이(small viewport, 주소창이 나와 있을 때 높이)**로 잡히면 같은 띠가 남음. 사파리로 열었는지, 홈 화면 아이콘으로 열었는지 **확인 필요**(강콩에게 물음).
- 고칠 것:
  1. `html, body, #game` 높이를 **큰 화면 높이**로: `height: 100lvh`(지원 안 하면 `100vh`), `#game`은 `top:0; left:0; width:100vw; height:100lvh`. 캔버스는 지금처럼 `#game` 실제 크기.
  2. 홈 화면 앱(standalone)일 때는 `window.screen` 가로·세로 중 큰 값/작은 값으로 한 번 더 확인해 더 큰 쪽을 씀.
  3. 단추·조이스틱·체력바는 `env(safe-area-inset-*)`로 안전 영역 안(지금처럼).
  4. `<meta name="theme-color" content="#1d1a14">` 추가(사파리 막대 색이 바탕과 같게).
  5. 관리자 창 설정 탭 맨 아래에 작은 글자로 "화면 innerHeight / visualViewport / #game / 캔버스 / screen / standalone 여부"를 보여 줌 → 강콩이 아이폰에서 찍어 보내면 원인을 바로 앎.
- 시험: 지금 `screenfill` 시험에 "단추 맨 아래 끝 + 안전 영역 = 화면 아래 끝"인지 추가.

## 2. 무예창에서 아래로 내리면 무예 칸이 또 있음 — 화면 단추와 연결이 안 되는 것처럼 보임

- 원인(기획 쪽 판단, 확인 필요): 무예창 정보 아래 「무예 칸」 줄(`src/ui/skillPanel.js` `slotRow`)이 **예전 모양(1~4·5~8, 9는 끝에 한 칸)**으로 1부터 차례로 늘어서 있음. 화면 오른쪽 아래 숫자패드는 **7·8·9 / 4·5·6 / 1·2·3** 모양이라 같은 칸인데 다른 곳처럼 보임. (주석도 "무예 칸 8개"로 옛날 그대로)
- 고칠 것:
  1. 무예창의 무예 칸을 **화면 숫자패드와 똑같은 3×3 모양·번호·아이콘**으로(공격·무예창 칸은 빼고 9칸만). 제목 "오른쪽 아래 무예 칸".
  2. 무예창에서 「칸에 넣기」를 누르면 **화면의 실제 숫자패드도 금빛으로 깜빡이고, 그 칸을 바로 눌러도 넣어짐**(무예창 안 3×3과 같은 동작).
  3. 숫자패드 칸을 길게 누르면 무예창이 그 칸을 고른 채로 열림(빼기·바꾸기).
- 시험: 무예창 3×3의 i번 칸과 화면 숫자패드 i번 칸이 같은 무예를 보여 주는지, 어느 쪽에서 바꿔도 다른 쪽이 바로 바뀌는지.

## 3. 숙련 5·10등급에 무예 이름이 바뀜 (강콩: 바람의나라처럼)

- 바람의나라는 윗단계 기술을 배우면 이름이 바뀌었음 → 우리는 숙련 등급으로: **1~4등급 = 기본 이름, 5~9등급 = 둘째 이름, 10등급 = 마지막 이름**. 효과(숙련 덤)는 지금 그대로, 이름·아이콘 테두리·연출 글씨만 바뀜.
- 이름표(임시, 강콩이 고쳐도 됨 — `data/skills.json` 무예마다 `names: [기본, 5등급, 10등급]`):

|---|---|---|
| 힘껏 베기 | 일도양단 | 개산일도 |
| 숨 고르기 | 조식 | 운기조식 |
| 휘돌려 베기 | 선풍참 | 대선풍 |
| 삼연참 | 삼재검 | 삼재연환검 |
| 질풍참 | 질풍일섬 | 섬광질풍 |
| 호통 | 사자후 | 대사자후 |
| 지축 가르기 | 열지참 | 천붕지열 |

- 이름이 바뀌는 순간: 머리 위 붓글씨를 크게 "검풍 → 검기"(10등급은 금빛 + 별빛 터짐 `fx_star_burst` 작게) + 소리. 무예창·정보창·시전할 때 뜨는 이름 글씨 모두 새 이름.
- 아이콘 테두리(그림 없이 코드로): 1~4 지금 그대로, 5~9 **은빛 테두리**, 10 **금빛 테두리 + 아주 약하게 반짝임**. 숫자패드 칸에도 보임(작아도 테두리 색은 보임).
- 패시브는 숙련이 없으니 이름도 그대로.
- 합성 무예(나중): 이름에 **주 무예의 지금 등급 이름**을 씀(예: 검기 + 뇌전 = "뇌전 검기"). 합성 무예 자체가 5·10등급이 되면 앞에 **진(眞)**·**극(極)**을 붙임 → `fusion_design.md`에도 적음.
- 저장할 것 없음(등급에서 계산). 정보창에 "다음 이름: 검기 (5등급)" 한 줄.
