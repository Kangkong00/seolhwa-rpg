# 머리 장비 (두건 → 모자 → 관)

## 방식 (2026-10-11 강콩 확정)

- 머리 장비는 **하나만 그려서 옷 6종 모두에 공용**으로 씌웁니다. 옷마다 따로 그리지 않습니다.
- 그림 만드는 법: 홑옷 3방향 시트를 참조로 **홑옷 아이가 그 장비를 쓴 3방향 시트**를 Flow로 뽑고, 기획 쪽이 장비 부분만 오립니다(머리에 꼭 맞는 모양을 얻기 위함). 장비만 단독으로 그리는 방식은 머리 모양·크기가 맞지 않아 기각.
- 시안: `docs/hood_outfits.png`(옷 6종 서 있기), `docs/hood_poses.png`(옷 6종 모든 자세 — 걷기·주먹·들고 있기·휘두르기).

## 붙이는 법 (코드)

1. 머리 장비를 착용하면, 몸 그림에서 해당 상투 지우개 부분을 지운 그림을 씀(불러올 때 한 번 만들어 두면 됨). 두건 윗선 위로 삐져나오는 상투만 지우고, 치켜든 주먹·팔은 남아 있음.
2. 장비 그림을 몸 그림 위에 그림: 장비 그림의 `from` 점을 몸 그림 캔버스의 `to` 점에 맞추고, `rotDeg`(화면 기준 시계 방향 +)만큼 돌리고 `scale`배. 몸 그림과 같은 배율·같은 좌우 반전·같은 걷기 들썩임을 따름.
   - 서 있기·걷기(`front`·`front_step` 등)는 `from = to`, 회전 0, 1배 → 그대로 겹침.
   - 640 폭 자세 그림(주먹·들고 있기·휘두르기)은 값대로 옮김. 측정값은 회전 −1~6도, 크기 0.96~1.02배.
3. 그리는 순서: 몸 → 머리 장비 → 무기 → 손 덮개.
4. 아직 그림이 없는 자세(옷 2~6의 무기 자세)는 그림이 생기면 기획 쪽이 값과 지우개를 추가함.

## 반영됨 (2026-10-11)

- 머리 칸에 낀 장비(`data/items.json`의 `head` = 그림 폴더)를 **불러올 때 몸 그림에 합쳐 한 번 만들어 둠**(`src/scenes/characterFrames.js` `loadHeadImages`·`wearHead`): 몸 그림마다 상투 지우개 부분을 지우고, `head_anchor.json` 값대로 머리 장비를 얹음. 그래서 배율·좌우 반전·걷기 들썩임·외곽선이 몸 그림과 같이 따라가고, 그리는 순서는 자연히 몸(+두건) → 무기 → 손 덮개.
- 걷기 다리 반전 프레임은 두건을 얹은 걷기 그림에서 만듦(머리는 기준선 위라 영향 없음). 손 덮개는 그대로.
- 위치값이 없는 그림은 머리 장비를 몸 그림 가로 가운데에 그대로 얹음(지금은 해당 없음 — 옷 2~6 무기 자세는 그림이 없어 주먹으로 침).
- 두건을 끼고 벗거나 옷을 바꾸면 그 옷 그림을 새로 만들고, 바꾼 뒤 옛 그림을 지움.
- 위치 파일 경로는 `data/items.json` `headAnchors`.

## 검증

- `head_anchor.json` 값으로 다시 배치한 결과가 시안과 일치(알파 평균 차이 0.01 이하)함을 기획 쪽에서 확인.
- 새 자세 그림이나 새 모자가 생기면 `tools/art/`의 `hood_cut.py → hood_align.py → hood_export.py` 순서로 다시 만듦.
