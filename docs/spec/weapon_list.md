# 무기 목록 v2 — 20종, 더 멋있게 (2026-10-18 강콩)

> **2026-10-22부터 데미지·체력·방어력은 이 파일 표의 ×10**(경험치·엽전·값은 그대로, 방어력은 비율식 — `feedback_1022.md` 8). 이 표는 10배 전 값.

## 결정

- 계획서의 "10단계 22종(목검 3 → 청동검 3 → 철검 3 → 환두도 3 → 환두대도 3 → 직도 3 → 장검 → 환도 → 사인검 → 칠성검)"을 **이 목록으로 바꿈**. 이유: ① 10-15에 그림까지 만든 쇠칼 3종이 옛 목록에 없음 ② 쇠 다음에 청동이 오는 순서가 어색함 ③ 이름이 밋밋해 "더 멋있는 디자인"(강콩)과 맞지 않음. 사인검·칠성검을 마지막에 두는 것은 옛 목록 그대로.
- 구간마다 2자루: **첫째 = 대장장이에서 삼**, **둘째 = 그 구간 우두머리 재료로 만듦**(더 화려함, 무기마다 고유 연출).
- 디자인 원칙(모든 무기): 곧은 한국 칼(환두·직도·환도 계열), 작고 둥근 코등이, 일본 칼(휜 날·네모 코등이·마름모 손잡이 감기)과 서양 칼(십자 코등이)처럼 보이지 않게. 구간이 오를수록 장식(금은 상감·문양·보석)과 **빛나는 문양**(구간 5부터)이 늘어남.
- 그림 규격: 240×960, 쥐는 점 (120,800), 칼끝 위(`docs/spec/weapons.md`). 길이(칼끝 거리)는 구간마다 조금씩 늚.

## 연출 단계 (타격감, `skills_impact.md`와 함께)

- 무기 구간(1~9)마다 맞힐 때 연출의 크기·밝기가 올라감 — 같은 들쥐를 때려도 칠성검이 훨씬 화려해야 함.
- 무기마다 `fx` 묶음을 `data/weapons.json`에 둠: `trailColor`, `trailParticles`(없음·꽃잎·불꽃·별·구름·먼지), `hitFx`(불꽃·독안개·할퀸 자국·여우불·땅 금·별빛 폭발), `fxTier`(1~9, 크기 배율). 그림 없이 코드로.
- 무기 그림이 오기 전에는 비슷한 무기 그림을 물들여 임시로 씀(쇠칼 때와 같음).
