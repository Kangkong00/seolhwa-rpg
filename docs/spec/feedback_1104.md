# 2026-11-04 강콩 피드백 + 조합 설계 v1

## 1. 무예창에서 북두칠성검이 혼자 떨어져 있음 → Claude Code

- 원인(`src/ui/skillPanel.js`): 가지(검술·풍술·기공·심법)는 세로 줄로 그리고, 끝 무예(칠성검무 = 10등급 이름 북두칠성검)는 줄들 **아래에 따로 한 줄**(`sk-final`)로 그림. 앞 무예(백호일섬·뇌전참)와 잇는 선이 없고, 가지마다 무예 수가 달라(검술 4·풍술 5·기공 3) 끝 무예만 동떨어져 보임.
- 고칠 것:
  1. **레벨 줄 맞춤**: 가지 줄 안의 무예를 배우는 레벨대로 같은 높이에 놓음(행 = 레벨 구간: 2~5 / 8~12 / 15~18 / 21~24 / 28~33 / 40). 빈 자리는 비워 둠 → 가지마다 길이가 달라도 표처럼 가지런함.
  2. **끝 무예는 마지막 행(40)**, 앞 무예 두 개(검술 줄의 백호일섬, 풍술 줄의 뇌전참) **사이 가운데 아래**에 놓고, 두 무예에서 내려오는 선이 끝 무예로 모이게(ㄴ·ㄱ 꺾은선). 배웠으면 선이 금빛.
  3. 끝 무예 칸은 조금 크게(1.2배) + 금빛 테두리, 위에 작은 글씨 "끝".
- 시험: 무예창 찍기(아이폰 가로)에서 끝 무예 칸 가운데 x가 두 앞 무예 칸 가운데 x의 평균과 같은지, 선이 두 칸에 닿는지.

## 2. 속성 상성(불·물 같은 것으로 데미지가 달라지는 것) — 하지 않음 (강콩 확정)

- 강콩: "속성을 부여해 상성에 따라 데미지 차이가 생기는 건 아닌 것 같다. **보여지는 게 더 중요**하다."
- 그래서 `fusion_design.md` 2-3 "기운 맞춤(무예 기운 = 무기 기운이면 데미지 +15%)"은 **데미지 덤을 빼고 보이는 것만**으로 바꿈: 기운이 맞으면 무예 연출에 **무기 기운 색이 한 겹 더 겹치고 칼 궤적이 무예 색으로 물듦**. 숫자 차이 없음.
- 계획서 기각안에 "속성 상성 데미지"를 적음(다시 제안하지 않음).

## 3. 조합(만들기) 설계 v1 — 기획 쪽 초안, 강콩 확인 전 (코드 아직 안 함)

지금 전리품은 **팔기**(+ 우두머리 재료로 칼 사기)만 됨. 조합을 넣어 **주운 것마다 쓸 데**가 생기게 함. 강콩 우선순위(① 무예 연출 ② 무기 디자인·연출)에 맞춰 **"보여지는 것"을 만드는 조합을 중심**에 둠.

### 원칙

- **조합은 실패 없음**(합성은 도박, 조합은 확실함 — 둘의 맛을 나눔).
- 마을 사람마다 「만들기」 메뉴: 자기 가게 물건만 만듦(가게 성격 유지).
- 알려진 조합은 목록에 보임. **숨은 조합**은 목록에 없고, 조합 창에 재료를 마음대로 넣어 보다 찾음(틀리면 재료는 돌려줌 → 마음껏 시험). 숨은 조합은 `secrets.md`에만.
- 값은 `data/recipes.json`(재료·개수·엽전·결과). 모두 임시값.

### 3-1. 무기 꾸미기 — 대장장이 「꾸미기」 (가장 중요, 그림 없이 코드로)

칼 한 자루에 **궤적 물감** 1개를 바를 수 있음(바꾸면 덮어씀). 휘두를 때 궤적 색·흩날림이 바뀜 = 내 칼이 남과 달라 보임. 무기 합성(새김)과 따로 쌓임.

| 물감 | 재료 | 모습 |
|---|---|---|
| 먹빛 궤적 | 물뱀 독니 2 + 구렁이 비늘 1 | 검붉은 먹물이 번지는 궤적 |
| 은가루 궤적 | 반짝이는 조약돌 5 | 은빛 반짝이가 흩날림 |
| 단풍 궤적 | 너구리 털가죽 2 + 너구리 꼬리털 1 | 붉은 단풍잎이 궤적을 따라 흩날림 |
| 여우불 궤적 | 여우 털가죽 2 + 여우불 구슬 1 | 푸른 불꽃 꼬리 |
| 흑웅 궤적 | 곰 가죽 2 + 흑웅 발톱 1 | 검은 궤적 + 금빛 테두리 |
| 산군 궤적 | 늑대 송곳니 3 + 산군 가죽 1 | 흰빛 궤적 + 범 무늬 줄 |

- 칼 이름 옆 정보창에 "궤적: 여우불". 물감 아이콘은 나중에 Flow(그 전엔 글자 칸).

### 3-2. 약·음식 — 약방 영감·주모 「만들기」

| 결과 | 재료(+엽전) | 효과 |
|---|---|---|
| 탕약 ×2 | 쥐수염 2 + 물뱀 허물 1 (+10푼) | 지금 탕약과 같음(사는 것보다 쌈) |
| 주먹밥 ×3 | 쌀 한 줌 3 + 쥐고기 1 | 지금 주먹밥 |
| 탁주 | 쌀 한 줌 6 | 지금 탁주 |
| 귀환 부적 ×3 | 황모 1 (+5푼) | 지금 귀환 부적 |
| **보혈탕**(새) | 들개 이빨 2 + 꿀단지 1 | 최대 체력 60% + 10초 동안 받는 데미지 −20% (`med` 묶음) |
| **멧돼지 산적**(새) | 멧돼지 고기 2 + 꿀단지 1 | 최대 체력 40% + 30초 걸음 +10% (`food` 묶음) |

### 3-3. 신발·토시 다듬기 — 갖바치·포목점 「다듬기」

- 낀 신발·토시를 **+1 ~ +3**까지 다듬음(그 장비 방어·걸음 +5%씩). 재료 = 그 구간 가죽·털가죽 + 엽전. 실패 없음. 무기 강화는 계획서 "무기 강화"와 겹치므로 따로 설계.

### 3-4. 숨은 조합 (후보 — 강콩이 고름)

- **경옥고**: 산삼 1 + 꿀단지 2 (약방) → 최대 체력 +20 영구(5번까지). 경옥고는 실제 전해 내려오는 보약 이름.
- **여우구슬 방울**: 여우불 구슬 1 + 여우 방울 1 (방물장수) → 이 방울을 가방에 넣고 있으면 밤… 대신(시계 없음) 여우굴에서 산삼 확률 ×2.
- 이름 모를 조합: 엉뚱한 두 재료(예: 쥐고기 + 산군 가죽)로 "?" 물건이 나오는 장난 1~2개.

### 3-5. 만드는 순서

1. 조합 창·`recipes.json`·마을 사람 「만들기」 + 3-2(약·음식) → 2. 3-1 무기 꾸미기(궤적 물감) → 3. 3-3 다듬기 → 4. 숨은 조합.
- 새 아이콘(물감 6·보혈탕·멧돼지 산적·경옥고 등)은 다음 Flow 세트에(그 전엔 글자 칸).


## 4. 조합 v2 — 새 무기·새 디자인·무기 무예 (11-04 16:54 강콩)

강콩: 꾸미기만이 아니라 **조합하면 새 무기가 생기고, 새 디자인이 생기고, 그 무기의 무예도 생기는** 특별함. "새 무기만 얻을지, 기존 무기에 무언가를 조합해 특수 무기가 생길지" 고민 필요.

### 4-1. 세 가지 길 비교

| 길 | 무엇 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| (가) 재료만으로 새 무기 | 재료 n개 → 처음 보는 칼 | 단순 | **이미 있음**: 구간마다 둘째 칼은 우두머리 재료 + 엽전으로 대장장이가 만듦(`weapon_list.md`) → 새로움이 적음 |
| **(나) 기존 무기 + 특별 재료 → 특수 무기(변형)** | 쓰던 칼에 재료를 먹여 다른 칼로 다시 태어남 | 쓰던 칼이 버려지지 않음, 바탕 칼 그림을 참조로 그려 **디자인이 이어지면서 달라짐**, 그 칼만의 **무기 무예**를 붙이기 좋음, 숨은 조합과 잘 맞음 | 변형마다 그림(칼·아이콘·무예)이 들어감 |
| (다) 무기 + 무기 → 새 무기 | 칼 둘을 합침 | 도박 맛 | **무기 합성(새김, `fusion_design.md` 2)과 겹침** |

**기획 쪽 권장: (나)를 조합의 중심**으로. 역할을 나눔:
- **조합(대장장이 「조합」)** = 정해진 재료로 **확실하게** 특수 무기가 됨(실패 없음). 새 이름·새 그림·무기 무예.
- **무기 합성(새김)** = 무작위로 성질을 새김(도박). 특수 무기에도 새길 수 있음.
- **궤적 물감(꾸미기)** = 3-1 그대로, 덤으로 남김.

### 4-2. 특수 무기 규칙 (초안)

- 바탕 무기 + 특별 재료(우두머리 재료·숨은 재료) + 엽전 → 특수 무기. **바탕 무기는 사라짐**(다시 태어남). 강화·새김·물감은 이어받음.
- **계보**: 바탕 → 변형 1단 → (대표 칼만) 변형 2단. 화면 칼 그림은 단계마다 바뀜.
- 특수 무기는 같은 구간 최고 칼보다 **조금 셈**(+10%, `secrets.md` 원칙 3 안). 숫자보다 **무기 무예와 모습**이 핵심.
- **무기 무예**: 특수 무기마다 1개, **그 칼을 들고 있을 때만** 씀. 자리 = 숫자패드 오른쪽 위 칸(지금 「무예창」 칸 — 무예창은 위쪽 「무예」 단추로 이미 열 수 있음). 칼을 바꾸면 그 칸도 바뀜, 맨손·보통 칼이면 그 칸은 「무예창」 그대로.
- 무기 무예는 숙련·합성 재료가 아님(칼에 딸린 것). 숙련 대신 **칼의 단계(변형 1단·2단)로 연출이 커짐**.
- 조합법 알기: 대장장이 대사로 힌트 하나씩("청풍검에 여우불을 먹이면 비가 온다던데…"), 일부는 숨은 조합(목록에 없음, `secrets.md`).

### 4-3. 시범 3자루 (그림·연출·재미 확인용, 이것부터)

| 바탕 → 특수 무기 | 재료(임시) | 모습 | 무기 무예 |
|---|---|---|---|
| 박달나무 목검(초반) → **엽전검** | 쥐왕의 엽전 꿰미 3 + 반짝이는 조약돌 5 + 100푼 | 붉은 끈으로 엽전 수십 닢을 엮어 만든 칼(옛 무당이 귀신을 쫓던 엽전 칼에서 따옴) | 「엽전비」: 휘두르면 엽전이 부채꼴로 튀어 앞 몬스터들을 맞힘, 맞힌 몬스터는 엽전을 조금 더 떨어뜨림 |
| 청풍검(구간 5) → **여우비검** | 여우불 구슬 2 + 너구리 꼬리털 1 + 3냥 | 맑은 하늘빛 칼날에 빗방울 무늬, 코등이에 작은 여우 방울 | 「여우비」: 앞쪽 넓게 햇빛 속 빛비가 내려 맞은 몬스터가 잠깐 홀림(멈칫) — "여우비"는 해 뜬 날 오는 비, 여우가 시집가는 날이라는 옛말 |
| 사인검(구간 9) → **사인참사검** | 산군 송곳니 2 + 여우 방울 1 + 40냥, **성황당 앞에서만**(숨은 조건) | 칼날 양면에 별자리(28수)와 글자가 금빛으로 새겨진 곧은 칼 — 실제 조선의 사인참사검에서 따옴 | 「참사」: 앞 일직선으로 별빛 칼자국 28개가 차례로 터짐, 10등급 마무리 그림급 연출 |

- 사인참사검은 `fusion_design.md` 3의 "무기 비전" 후보였던 것을 **조합의 숨은 조건**으로 옮김.
- 그림(무기마다): 칼 1장(바탕 칼 그림을 참조, 240×960 규격·쥐는 점 같게), 아이콘 1장, 무기 무예 효과 그림 1장(검은 배경) + 무예 아이콘 1장 → 3자루 × 4 = **12장**(Flow 세트 하나).
- 시범 3자루로 "조합 → 새 칼 → 새 무예"의 손맛을 확인한 뒤, 구간마다 1자루씩(모두 9~10자루)으로 늘림.
