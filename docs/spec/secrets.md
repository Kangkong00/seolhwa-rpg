# 숨은 장치 목록 (기획·코드 전용 — 게임 안에서는 안내하지 않음)

2026-10-22 강콩: 네이버웹툰 「99강화 나무몽둥이」처럼 **게임 속에 아무도 모르는 비밀 장치·무예·물건이 숨어 있게.** 무예 합성·무기 합성과 함께 "나만의 캐릭터"를 만드는 뼈대.

## 원칙 (안정성)

1. **여기 적은 것만 숨김.** 코드에 몰래 넣지 않고 이 목록과 `data/`에 모두 적음 → 기획·코드가 서로 잊지 않음.
2. 데이터에는 `"secret": true`를 붙임 → 가게 목록·무예창·정리본 표·도움말에서 빠짐. 관리자 창에서는 보임(시험용).
3. 숨은 것은 **세지만 판을 깨지 않음**: 같은 구간 장비·무예의 최고치 +20% 안. 영구 능력치는 횟수 상한을 둠.
4. 힌트는 마을 사람의 지나가는 말(`lines`) 한 줄 정도만. 강콩이 정함.
5. 저장 파일에 "찾은 비밀" 목록(`secretsFound`)을 남김 → 나중에 도감·업적으로 쓸 수 있음.
