# 몬스터

> 몬스터 그림 규격, 크기, 돌아다니기, 몬스터 구역. CLAUDE.md의 목차에서 연결됨. 내용을 고칠 때는 이 파일에서 해당 부분만 고치고, 파일 전체를 다시 쓰지 않음.

## 몬스터 `assets/monsters/<이름>/`

- 캔버스 **640×400, 투명 배경, 발 기준선 y=380, 가로 가운데**. 정면 서 있기 키를 240px로 맞춤(몸이 긴 옆면은 더 넓음).
- 파일 이름은 캐릭터와 같음: `front`, `side`(왼쪽을 봄), `back`, `front_step`, `side_step`, `back_step`. 오른쪽은 `side*` 좌우 반전.
- 네 발 동물이라 다리 반전은 쓰지 않고 `step` ↔ `stand`를 번갈아 씀.
- `rat`(들쥐): 1376 기준 **표시 키 28px로 확정**(주인공 62의 약 45%, 2026-10-10 강콩). 표시 크기는 `data/monsters.json`의 `height`.
- `bigrat`(큰 들쥐, 들쥐굴 우두머리): 서 있기 3장 + 걷기 3장. 표시 키는 **일반 들쥐보다 조금만 크게(2026-10-10 강콩)** — 권장 36px(들쥐 28의 약 1.3배), 아이폰에서 보고 조정. 정면 걷기 그림은 한쪽 앞발을 든 자세.
- **몬스터 돌아다니기 (2026-10-10 강콩 확정)**: 개발 단계에서는 들쥐·큰 들쥐 모두 **같은 조건**(속도·쉬는 시간·다시 생기는 시간 등 동일, 다른 것은 크기와 돌아다니는 범위뿐). 들쥐는 **자기 구역 안에서만**, 큰 들쥐는 **맵 전체(갈 수 있는 칸 전부)**를 돌아다님. 들쥐굴 1층에 큰 들쥐도 둠. 우두머리다움은 나중에 **다시 생기는 시간(젠 시간)만 길게** 해서 줌 — 숫자는 `data/`에 임시값. 쫓아오기·공격은 전투 단계에서.

## 몬스터 구역 `spawnZones` (맵 JSON)

- `{ name, monster, count, respawnMs, x, y, w, h, roam? }`: 구역 안에 `count`마리를 두고, 줄어들면 `respawnMs` 뒤에 한 마리씩 다시 생김. 몬스터는 구역 밖·벽으로 못 감. `roam: "map"`이면 사각형은 처음 생기는 자리일 뿐이고 맵 전체(갈 수 있는 칸)를 돌아다님(큰 들쥐). `noSpawnNearPortal`(픽셀) 안에는 생기지 않음. 격자 보기에서 보라 사각형.
- 움직임: 쉬기 ↔ 4방향으로 조금 걷기. 종류별 `speed`·`restMs`·`walkDistance`·`walkFrameMs`·`footBox`는 `data/monsters.json`(모두 임시값). 공격·쫓아오기는 아직 없음.
- 규칙 코드는 `src/core/monsters.js`(화면 무관), 그리기는 `src/scenes/MonsterView.js`.
- 들쥐굴 1층: 들쥐 둥지 방 3, 창고 방 3, 가운데 싸움터 4마리 + 큰 들쥐 1마리(싸움터에서 생겨 맵 전체를 돌아다님). 모두 10초마다 다시 생김(임시값, 같은 조건). 큰 들쥐 표시 키 36(`data/monsters.json`).

레벨·경험치·전투 수치는 아직 정하지 않았습니다. 임의로 확정하지 말고 `data/`에 임시값으로만 두세요.
