# 타격감 키우기 + 무예 늘리기 (2026-10-18 강콩)

강콩: "임팩트 디자인은 더욱 화려해져야 하고, 타격하는 임팩트도 더 키워야 한다. 스킬도 다양해져야 한다. 나중에는 직업도 다양해질 것." → 그림 없이 코드로 바로 할 수 있으므로 **사냥터 그림보다 먼저** 반영.

## 1. 타격감 (모든 공격 공통)

지금 값(`data/game.json` `swingFx`·`hitFx`)은 "아주 약하게"로 시작한 것 → 전체적으로 키움. 모두 임시값, `data/`에서 조정.

| 항목 | 지금 | 바꿈 |
|---|---|---|
| 맞는 순간 멈춤 `hitStopMs` | 60 | **85** (무예는 지금처럼 배율) |
| 화면 흔들림 `shakeIntensity`·`shakeMs` | 0.0025·90 | **0.004·110** |

- 소리: 회심·쓰러뜨림 소리를 코드 소리로 추가(`docs/spec/sound.md` 방식).

## 3. 나중에 직업이 늘 때를 위한 준비

- `data/skills.json` 무예마다 `job`: `"geomgaek"`(검객, 가칭)을 붙임. 직업 고르기 화면은 지금 만들지 않음.
- 무예 연출 코드는 `kind`별로 나눠 다른 직업도 같은 틀(돌진·날아감·주변·여러 대상·자세·궁극)을 쓸 수 있게.
- 직업 후보(기획만, 확인 필요): 검객(칼) · 궁수(활) · 도사(부적·도술) · 무당(방울·부채, 회복). 그림이 많이 들므로 혼자 하는 버전이 완성된 뒤.

## 반영됨 (2026-10-18, Claude Code)

### 1. 타격감
- `data/game.json`: `swingFx` hitStopMs 85·shakeMs 110·shakeIntensity 0.004·먹 방울 10개(크기 3), `hitFx.flashMs` 120, 숫자 `numbers.crit`(32px 금색 + "회심!" 14px). 새 묶음 `impact`(섬광 별·베인 자국·찌그러짐·fxTier 배율·회심·쓰러뜨림 값, 모두 임시).
- 모든 맞힘(주먹·휘두르기·무예)을 `MapScene.impactHit` 한 곳에서: 회심 판정(`src/core/combat.js` `rollCrit` — 8%, ×1.8) → 체력 → 숫자 → 흰 섬광 별 4갈래(지름 26, 120ms) + 베인 자국(칼 방향 사선, 흰 → 무기 궤적 색, 180ms, 맨손이면 없음) + 먹 방울 → 몬스터 찌그러짐(가로 1.15·세로 0.9, 100ms) → 멈춤·흔들림·소리. 그림은 `src/scenes/impactFx.js`.
- 회심: 멈춤 ×2, 금빛 섬광 별 2배(1.5배 길게), 흔들림 ×2, 소리 `crit`(코드 소리 "챙").
- 쓰러뜨림: 마지막 한 대 멈춤 ×1.5, 맞은 방향으로 24px 튕겨 40° 돌며 날아간 뒤 흰 연기 8방울(`MonsterView.dieFly`), 소리 `kill`.
- 무기 `fx` 묶음: `data/weapons.json` 무기마다 `fx: { fxTier, trailParticles, hitFx }` — 목검 3종 fxTier 1, 쇠칼 3종 fxTier 2. fxTier마다 섬광·베인 자국·먹 방울 크기 +8%. `trailParticles`·`hitFx`는 자리만(구간 5 무기가 올 때 만듦).

### 2. 무예 10개 + 칸 4개 + 무예창
- `data/skills.json`에 10개 추가(표의 레벨·효과·기다리는 시간 그대로, 모두 `job: "geomgaek"`, 칼 무예 4개 `needsBlade`). 값·재료(임시, 제가 정함 — 확인 필요): 삼연참 3냥 + 쥐가죽 8·쥐수염 4, 질풍참 5냥 + 족제비 가죽 3, 호통 8냥 + 족제비 고기 5, 지축 가르기 12냥 + 황모 2, 그 뒤(그 구간 전리품이 아직 없음)는 엽전만: 검풍 18냥, 받아치기 25냥, 회오리 베기 35냥, 뇌전참 50냥, 백호일섬 80냥, 칠성검무 150냥. 배우는 곳은 늙은 군관(배우면 빈 칸에 자동으로 들어감).
- 동작은 `src/scenes/skillKinds.js`에 kind별로(다른 직업도 같은 틀): `chain`(삼연참 — 휘두르기를 0.7배 빠르게 3번 이어감, 궤적이 0.5초 남고 위아래로 엇갈림, 마지막은 밀어내기 2배·큰 섬광) · `dash`(질풍참·백호일섬 — 미끄러지며 길 위 몬스터를 벰, 잔상, 흰 바람 줄, 백호일섬은 호랑이 무늬 줄 + 0.3초 뒤 한꺼번에 터짐) · `shout`(호통 — 동심원 3개, 흔들림, 몬스터 머리 위 "!", 1.2초 멈칫) · `line`(지축 가르기 — 내려치는 순간 땅 금이 앞으로 달리며 돌 조각, 금이 지나가는 자리 맞힘) · `projectile`(검풍 — 무기 궤적 색 반달이 날아가며 꿰뚫음, 벽에서 사라짐) · `stance`(받아치기 — 금빛 칼막, 그 사이 물리면 데미지 0 + 반드시 회심 3배 반격) · `spin`(회오리 베기 — 휘돌려 베기 틀에 안쪽 고리·나뭇잎 회오리·끌어당김 추가) · `multi`(뇌전참 — 가까운 5마리에 차례로 번개·그을음·화면 번쩍) · `ultimate`(칠성검무 — 땅에 북두칠성, 별을 차례로 켜며 베고 마지막 금빛 폭발). 연출 그림은 `src/scenes/skillFx.js`.
- 칼 무예는 맨손이면 칸이 흐리고 누르면 "칼이 있어야 합니다".
- 무예 칸 4개(`src/ui/skillButtons.js`, 공격 단추 둘레 호), PC 1~4. 빈칸을 누르면 무예창이 열림.
- 무예창(`src/ui/skillPanel.js`): 위쪽 단추 줄 `무예`(PC K). 배운 무예를 누른 뒤 칸을 누르면 넣음(다른 칸에 있으면 맞바꿈), 찬 칸을 누르면 뺌. 배우지 않은 무예는 흐리게 + 레벨. 칸은 저장(`skillSlots`, 규칙은 `src/core/skills.js` `normalizeSlots`·`placeInSlot`·`clearSlot`·`autoSlot`).
- 무예 아이콘: 아직 그림이 없어 한자 `icon`. 모든 무예에 `image: assets/items/icons/skill_<id>.png`를 적어 둠 → 그림이 오면 코드 수정 없이 바뀜.
- 소리 `shout`(호통)·`thunder`(번개)를 코드 소리로 추가.
