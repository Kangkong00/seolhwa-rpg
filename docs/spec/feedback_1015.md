## 2. 데미지 숫자

`data/game.json`에 이미 데미지 숫자 값이 있음(13px 흰색) — **강콩 화면에서 안 보였음: 너무 작거나 안 뜨는 것, 확인 필요**. 아래로 바꿈:

| 경우 | 모양 |
|---|---|
| 몬스터가 맞음(공격) | 흰색 **22px**, 짙은 갈색 테두리 3px |
| 몬스터가 맞음(무예) | **금색 26px**, 같은 테두리 |
| 주인공이 맞음 | **빨강 22px**, 주인공 머리 위 |
| 회복 | **초록 "+n" 22px** |

- 뜰 때 0.12초 동안 1.4배 → 1배로 "톡" 튀고, 위로 떠오르며(`floatPx` 28) 0.6초 뒤 흐려짐.
- 0.3초 안에 여러 개가 뜨면 좌우로 ±10px 흩뜨려 겹치지 않게(휘돌려 베기).
- 숫자도 카메라 1.0배 기준 크기. 글꼴은 지금 쓰는 굵은 글꼴.

7. **새 무기 3종(데이터만)**: `data/weapons.json`(공격력·swingMs·cooldownMs·칼끝 거리·궤적 색 — 표 그대로, `reach`는 칼이 길어진 만큼 50·52·54로 조금 늘림, 임시), `data/items.json`(레벨 6·9·12, 설명, 파는 값 30·70·180푼 — 임시, `shopPrice`에 대장장이 값). 그림이 오기 전엔 목검 그림을 흑백으로 바꾼 뒤 회색(`tint`)으로 물들여 씀, 아이콘도 목검 아이콘에 CSS 필터(`iconFilter`). 레벨이 모자라면 정보창 빨강 "레벨 N부터" + 끼기 흐림(규칙에서도 막음). **대장장이(파는 곳)는 그림이 오면 붙임** — 그때까지 새 무기를 얻는 길은 없음.
