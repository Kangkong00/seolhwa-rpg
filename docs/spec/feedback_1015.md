## 1. 무예 연출 (새 그림 없음, 코드 효과)

지금은 무예를 써도 일반 공격과 거의 같아 보임. 무예마다 "썼다"는 게 한눈에 보이게:

| 무예 | 연출 |
|---|---|
| 힘껏 베기 | ① 모으기 0.25초: 칼에 금빛이 번지며 몸이 살짝 뒤로(지금 lean 재사용) ② 휘두를 때 궤적 굵게(지금 `trailWidthMul`) + 칼 색 대신 **금빛 궤적** ③ 앞쪽으로 **금·흰 반달 충격파**가 약 60px 퍼지며 0.25초에 사라짐 ④ 맞은 몬스터에 큰 먹 튐·흔들림(지금 배율 유지) |
| 숨 고르기 | ① 발밑에서 **푸른 고리 2개**가 0.15초 간격으로 퍼짐(지름 20 → 70px, 0.6초) ② 몸에서 **작은 빛 알갱이 10개**가 위로 떠오르며 사라짐(1.2초) ③ 머리 위에 **초록 회복 숫자 "+8"** (아래 2번) ④ 지금 몸 빛남(`glowColor`·`glowMs`) 유지 |
| 휘돌려 베기 | **지속형으로 바꿈**: `spinMs` 480 → **2000**(약 2초 동안 계속 돎, 한 바퀴 400ms = 5바퀴). **0.4초마다** 반경 안 몬스터를 모두 때림(`tickMs` 400, 한 번에 `damageMul` 0.7 — 5번 맞으면 일반 공격 3.5배). 도는 동안 **천천히 움직일 수 있음**(걸음의 60%, `moveMul` 0.6). 몸 둘레에 **반투명 바람 고리**(반경 `radius`, 흰빛, 돌면서 끊긴 호 3개가 빙빙)와 바닥 먼지. `cooldownMs` 10000 → **12000**. `radius` 42 → 48 |

- 무예 단추는 기다리는 시간 동안 어둡게 + 남은 시간 원형 표시(이미 있으면 그대로).
- 효과 색·시간은 `data/skills.json`에서 조정되게.

## 2. 데미지 숫자

`data/game.json`에 이미 데미지 숫자 값이 있음(13px 흰색) — **강콩 화면에서 안 보였음: 너무 작거나 안 뜨는 것, 확인 필요**. 아래로 바꿈:

| 경우 | 모양 |
|---|---|
| 몬스터가 맞음(공격) | 흰색 **22px**, 짙은 갈색 테두리 3px |
| 몬스터가 맞음(무예) | **금색 26px**, 같은 테두리 |
| 주인공이 맞음 | **빨강 22px**, 주인공 머리 위 |
| 회복 | **초록 "+n" 22px** |

- 뜰 때 0.12초 동안 1.4배 → 1배로 "톡" 튀고, 위로 떠오르며(`floatPx` 28) 0.6초 뒤 흐려짐.
- 0.3초 안에 여러 개가 뜨면 좌우로 ±10px 흩뜨려 겹치지 않게(휘돌려 베기).
- 숫자도 카메라 1.0배 기준 크기. 글꼴은 지금 쓰는 굵은 글꼴.

## 4. 마을 귀환 (귀환 부적은 이미 있음 — 찾기 쉽게)

- 지금: 귀환 부적(`item_return_charm`)은 성황당(마을 왼쪽 아래 서낭나무, x440 y726)에서 10푼에 팔고, 가방에서 누르면 마을로 돌아옴. **강콩이 못 찾음** → 아래로 보강:
- **시작할 때 3장** 줌(지금 저장에도 한 번만 넣어 줌).
- **화면 오른쪽 위 "가방" 왼쪽에 "귀환" 단추**: 부적 아이콘 + 남은 개수. 누르면 **1초 동안 몸이 푸르게 빛난 뒤** 성황당 앞으로 이동(그 사이 맞으면 취소, 부적은 안 줄어듦). 마을 안에서는 흐리게(못 씀). 부적이 0장이면 흐리게 + 누르면 "성황당에서 살 수 있다" 글자.
- 약방 영감도 귀환 부적을 팔게(마을 가운데라 찾기 쉬움, 같은 값).

## 5. 아이템 정보창

- 가방·장비창·가게에서 **아이콘을 누르면 정보창**(PC는 마우스를 올리면 작은 창, 누르면 정보창).
- 내용(위에서 아래로): 큰 아이콘(96px) · 이름 · 종류(무기/옷/머리/팔/발/전리품/먹을거리/쓰는 것) · **능력치**(아래 6번, 지금 낀 것과 비교해 오르면 초록 ▲, 내리면 빨강 ▼) · 설명 1~2줄(`data/items.json` `desc`, 아래 목록) · 파는 값 · 단추(끼기/벗기, 쓰기, 가게에서는 팔기·사기, 닫기).
- 창은 화면 가운데, 바깥을 누르면 닫힘. 가로 화면에서 높이 70% 넘지 않게.
- 설명(임시): 소나무 목검 "가볍고 거친 연습용 목검." / 참나무 목검 "단단한 참나무를 깎은 목검." / 박달나무 목검 "무겁고 단단해 한 대가 묵직하다." / 무명 두건 "머리를 감싸는 무명천." / 무명 토시 "팔뚝을 감싸 상처를 막는다." / 짚신 "가볍게 짠 짚신. 발걸음이 가볍다." / 전리품은 "○○에게 팔 수 있다.", "무예를 배울 때 쓴다." 같이 쓰임을 적음(가게 `buys`와 무예 `cost`에서 자동으로 만들어도 됨).

## 6. 능력치 (임시) — 정보창과 실제 전투에 같이 씀

- **공격력** = 무기 `damage`(맨손은 `attack.damage`) + 레벨 보너스(지금 `damageBonus`). 정보창에 "공격력 2", 휘두르기 빠르기는 "빠름/보통/느림"(`cooldownMs` 470 이하 빠름, 520 이상 느림).
- **방어력**: 맞을 때 데미지 − 방어력(최소 1). 옷·머리·팔 방어력 합.
  - 옷: 홑옷 0, 무명옷 1, 도포 1, 철릭 2, 두정갑 3, 신선복 2
  - 무명 두건 1, 무명 토시 1
- **걸음**: 짚신 +6%(`speed` 배율).
- `data/items.json` `stats`에 위 값을 넣고, 정보창·장비창에 합계(공격력·방어력·걸음) 표시.
