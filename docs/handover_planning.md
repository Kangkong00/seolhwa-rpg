## 1. 역할 나누기 (꼭 지킬 것)

- **기획 대화(이 대화)**: 기획, 문서(계획서·프롬프트 모음), Google Flow 프롬프트, 그림 가공(오리기·손 덮개·시안), 저장소에 **그림·docs·CLAUDE.md만** 올림.
- **Claude Code**: 게임 코드 전부. 기획 대화는 **게임 코드를 쓰거나 올리지 않음**(강콩이 분명히 지적한 적 있음). 대신 Claude Code에 붙여 넣을 **전달 내용**을 만들어 드림.
- **강콩**: 방향 판단, 최종 검토, Flow로 그림 생성, 전달 내용을 Claude Code에 넘김.

## 2. 강콩과 일하는 방식

- 존댓말, 결론부터, 확인 안 된 것은 "확인 필요", 추측은 추측이라고 표시. 쉬운 말로.
- 제안을 무조건 따르지 말고 솔직하게 평가하고 반론. 결정과 **기각안·이유**는 계획서에 남김(다시 제안하지 않게).
- Flow 프롬프트는 **Flow 전용 상세 프롬프트**, 부위별로 나열, 그대로 **복사해 붙이면 되는 완성본**으로(틀+빈칸 방식은 헷갈려 함). 여러 방향은 한 프롬프트로 한 번에. 작업은 최대한 간단하게.
- 그림을 받으면 **세심하게 검토**(방향별로 원한 것과 나온 것을 비교)하고, 쓸 수 없으면 솔직히 말하고 고친 프롬프트를 줌.
- 시안(합성 그림·GIF)을 먼저 보여 주고 검토받은 뒤 Claude Code 전달 내용을 짬.
- 답변 끝에 이어서 물어볼 질문은 하나만.

## 4. Flow 작업 요령 (해 보며 알게 된 것)

- 참조는 1~2장, 업로드 후 이름을 붙여 `@이름`으로 부름. 3방향 시트 1장이면 옷·얼굴이 잘 유지됨.
- 정면·뒷면에서 "앞으로"(화면 안팎)는 Flow가 **옆으로** 해석하기 쉬움. 이럴 땐 **시작 자세와 끝 자세 시트를 참조로 주고 "그 둘의 가운데"를 그리게** 하면 정확함(휘두르는 중간 자세가 이렇게 성공).
- 4명이 나오거나 옆면이 오른쪽을 봐도 괜찮음 — 골라 쓰고 반전.
- 손에 무기를 그리지 않게(빈 주먹, "막대를 쥔 듯"), 무기는 따로 그려 코드로 붙임.
- 워터마크(반짝이)는 1376×768 기준 오른쪽 아래 약 (1268,670). 그림 위에 걸치면 지워야 함.
- 무기는 일본 목도·서양 검처럼 보이지 않게(곧은 칼날, 작고 둥근 코등이).
- **그림체 바꾸기(다시 그리기)**: `@원본`(옛 그림) + `@새옷시트`/`@그림체`를 주고 "자세·배치·크기는 @원본 그대로, 그림체만"이라고 하면 위치가 유지됨(2026-10-12 마을·홑옷으로 확인).
- 모자류는 **홑옷 3방향 시트를 참조로 "그 장비를 쓴 모습"을 뽑으면** 인물 위치가 원본과 픽셀 단위로 같게 나옴 → 원본과 비교해 장비만 오려 모든 옷에 공용. 상투를 완전히 감싸고, 천에 구멍 없고, 얼굴 옆으로 내려오는 것 없게 써야 오리기가 깔끔함.
