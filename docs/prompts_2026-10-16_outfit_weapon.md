# Flow 프롬프트 — 옷 2~6 무기 자세 20장 (2026-10-16)

> 강콩 결정(10-16): 무명옷·도포·철릭·두정갑·신선복 모두 무기 자세를 만듦. 옷마다 4장(들고 서 있기·치켜들기·휘두르기 중간·내려치기). **들고 걷기는 Flow로 뽑지 않음** — 기획 쪽에서 "들고 서 있기 윗몸 + 기존 걷기 다리"로 합성(`docs/spec/weapons.md`, 10-11 확인한 방식).
> 방법: 홑옷 무기 자세 시트를 @자세(원본)로, 옷 시트를 @옷으로 주고 "자세는 그대로, 옷만 바꿈" → 인물 위치가 홑옷과 거의 같게 나와 쥐는 점·손 덮개를 같은 도구로 잼(10-12 그림체 전환 때 확인한 방식).

```
[참조 사용법]

@무명옷 의 옷(모양·색·무늬·띠·신발·장신구 전부)을 그대로 입힘: 흰 무명 저고리와 바지, 검회색 천 허리띠를 앞에서 묶어 늘어뜨림, 팔목과 종아리에 감은 흰 천, 짚신. 얼굴·갈색 머리·상투·체형도 @무명옷 를 따름.
```
