# Flow 프롬프트 136~138 — 무예 효과 그림 12장 (2026-10-22)

- 왜 그림인가: 지금 무예 연출은 코드로 그린 도형(호·원·알갱이)이라 아무리 키워도 "도형"처럼 보임. **붓으로 그린 효과 그림 한 장**을 코드가 키우고·돌리고·늘리고·흐리게 하면 훨씬 화려해짐. 여러 장짜리 움직이는 그림(프레임)은 Flow가 장마다 모양을 맞추지 못해서 안 씀 — **한 장 그림 + 코드 움직임**.
- **검은 배경**으로 뽑음 → 기획 쪽이 밝기로 투명하게 만들어(빛 효과는 검정 = 투명) `assets/fx/<id>.png`로 오림. 게임에서는 더하기 섞기(빛나게)로 그림.
- 참조 그림 없음(그림체만 맞춤). 받으면 기획 쪽이 오려 Claude Code에 넘김.

## 136. 무예 효과 4장 — 베기
```
[만들 것] 게임용 무예 효과 그림 4개를 가로 한 줄에, 서로 넉넉히 떨어지게, 왼쪽부터:
1. 붓 베기 초승달: 한 번의 굵은 붓 획으로 그린 커다란 초승달 모양 칼 궤적. 가운데는 흰빛, 바깥으로 갈수록 금빛, 끝은 붓이 갈라진 듯 가늘게 흩어짐.
2. 세 줄 베기 자국: 비스듬히 나란한 날카로운 빛 획 세 줄, 흰빛 중심에 붉은 금빛 테두리, 획 끝에 작은 불티.
3. 땅 가르기: 위에서 내려다본, 앞으로 길게 갈라진 땅의 금 한 줄기와 그 틈에서 솟는 주황빛, 양옆으로 튀는 작은 돌 조각.
4. 반달 검기: 옆으로 누운 푸른 반달 모양 칼바람, 앞쪽이 밝고 뒤로 빛 꼬리가 길게 흩어짐.

[그림체] 한국 전통 설화풍 게임 효과, 먹 붓 느낌이 살아 있는 빛나는 효과, 3D 렌더 느낌의 부드러운 빛 번짐, 밝고 맑은 색.

[출력] 단색 순수 검은 배경, 효과만(사람·칼·몬스터·땅 배경 없음), 글자·테두리·칸 나눔 선 없음, 정확히 4개, 각각 잘리지 않게, 가로로 긴 화면(16:9)
```
