# 글꼴

- `levelup_brush.woff2`: 나눔손글씨 붓(Nanum Brush Script, © NAVER Corporation)에서 레벨업 글자(`레벨 업!`, `레벨 0~9`)에 쓰는 글자만 뽑은 것. Google Fonts에서 받음(2026-10-12).
- 라이선스: SIL Open Font License 1.1 (https://openfontlicense.org). 글꼴만 따로 팔 수 없고, 고친 글꼴에 원래 이름을 쓰지 않는 조건으로 게임에 넣어 배포할 수 있음.
- 다른 글자가 더 필요하면 Google Fonts `css2?family=Nanum+Brush+Script&text=<글자>`로 다시 뽑아 교체.
