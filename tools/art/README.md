# 그림 가공 도구 (기획 쪽 전용)

기획 대화(그림 생성·가공 담당)가 Flow 그림을 게임용으로 오리고, 쥐는 점·손 덮개를 만들고, 합성 시안을 만들 때 쓴 파이썬 스크립트입니다. **게임 코드가 아니며 Claude Code는 고치지 않습니다.** 대화가 바뀌어도 같은 방법으로 작업할 수 있게 남겨 둔 것입니다.

스크립트 안의 파일 경로(업로드 폴더, 임시 폴더)는 그때그때 바꿔서 씁니다. 필요한 것: Python 3, Pillow, numpy, scipy, opencv-contrib-python(`dnn_superres`).

## 핵심 방법

| 일 | 스크립트 | 방법 |
|---|---|---|
| 흰 배경 오리기 | `cut2.py` `cutout()` | 테두리에서 이어진 흰색(최소값>225, 색 차이<25)을 지움 + 몸 안쪽에 갇힌 순백 구멍(최소값>244, 차이<9, 넓이≥25)도 지움 + 1px 넓혀 흰 테두리 제거 + 큰 덩어리의 2% 미만 조각 버림 + 알파 가우시안 0.6 |
| 시트에서 인물 나누기 | `punch.py` `segs()` | 세로줄에 그림이 있는지로 인물 구간을 나눔(15px 틈 허용). 붙은 경우는 연결 덩어리로 나눔(`rat2.py`, `bigrat.py`, `swing.py`의 `dropright`) |
| 640×720 캔버스에 놓기 | `punch.py` `place()`·`bodyx()` | 허리 높이(키의 60~70%) 가로 가운데를 x=320, 발을 y=700에 맞춤. 크기는 정면 키 640(서 있기 계열) 또는 뒷면 머리끝~발 640(휘두르기 계열) |
| 서 있기·걷기 6장 | `pipeline.py` | 옷마다 3방향 시트 → front/side/back(400×720, 가운데 x=200) |
| 주먹·휘두르기·들고 있기 | `punch.py`, `swing.py`, `hold.py` | 같은 방식, 640×720. 옆면이 오른쪽을 보면 좌우 반전 |
| 손 덮개 | `hands2.py` | 주먹 근처(반지름 34) 피부색 덩어리 + 4px 넓힘 → `<그림>_hand.png`. 주먹 위치는 눈으로 잰 값으로 시작 |
| 무기 오리기 | `weapon.py` | 기울기 보정 → 길이 맞춤(소나무 480) → 손잡이 가운데를 (120,800)에 놓는 240×960 캔버스 |
| 워터마크 지우기 | `punch.py` 앞부분 참고 | Flow 반짝이는 1376×768 기준 약 (1268,670). 배경 위면 `cv2.inpaint` TELEA 반지름 30, 신발 등 그림 위면 왼쪽 이웃 색으로 채움 |
| 맵 2배 키우기 | `up2.py`, `upd2.py` | EDSR ×4(모델 `EDSR_x4.pb`, raw.githubusercontent.com/Saafke/EDSR_Tensorflow/master/models/EDSR_x4.pb)를 160px 타일·8px 겹침으로 → INTER_AREA로 ×2 |
| 휘두르기 시안 | `swing3d.py`, `mock2.py`, `mock3.py` | 3D 방향 → 화면 투영(K=0.5), 쥐는 점은 지금 몸 그림의 주먹에 고정, 손 덮개를 맨 위에 |
| 궤적 시안 | `trail.py`, `sickle.py` | 정면·뒷면 사선 획 / 옆면 낫 모양 타원 호 |
| 배경과 어울림 시안 | `blend.py` | 마을 그림 위에 62px(아이폰 2배 = 124) 캐릭터 + 외곽선 비교 |
| 걷기 확인 GIF | `walkall.py` | 다리 반전 걷기 미리보기 |
| 머리 장비(두건) | `hood_cut.py` → `hood_align.py`(+`topknot.py`) → `hood_export.py` | ① 홑옷에 씌운 3방향 시트를 원본 홑옷 시트와 픽셀 비교 + 천 색으로 두건만 오림(피부는 절대 안 가져옴, 작은 구멍 메움) ② 자세마다 서 있기 머리를 찾아 위치·회전·크기 측정 ③ 두건 윗선 위로 나온 상투만 지우는 마스크(주먹·팔은 남김) ④ `assets/equipment/head/`로 내보냄. 새 모자도 같은 순서 |
| 아이템 아이콘 | `icons.py` | 256×256 투명, 여백 18px. Flow 아이템 시트는 반으로 나눠 `cutout`, 두건은 뒷면 그림, 목검은 45도 눕힘, 옷은 서 있기 정면 목 아래 |
